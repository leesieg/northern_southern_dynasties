# 风云南北朝

桌面浏览器单人策略游戏，以人物为中心的南北朝历史模拟 RPG。包含出行、仕宦、公私经济、家族、生活重心、战争与外交；正式地图使用 Three.js 战役渲染链路。历史区划、人口与人物资料仍有覆盖边界，示意县域不代表完整历史疆界。

## 本地运行与检查

需要 Node.js 22.12+。

```bash
npm ci
npm run dev
```

游戏入口：<http://127.0.0.1:5173/>。地图样板：<http://127.0.0.1:5173/map-sample.html>。服务仅监听本机；样板用于独立地图研究，不读取游戏存档。

```bash
npm run build
npm run preview
```

构建输出到 `dist/`；预览默认入口为 <http://127.0.0.1:4173/>。

按改动范围执行定向测试，例如：

```bash
npx vitest run src/core/peaceContiguity.test.ts
node --test tests/paintedAssets.test.mjs
```

全量 `npm test`、长局和完整游戏回归仅按用户明确要求执行。UI 默认由用户人工验收，专项授权按 `AGENTS.md` 执行；代码或构建通过不能代替画面与交互验收。

## 仓库目录

| 路径 | 用途 |
| --- | --- |
| `src/core/` | 独立于浏览器的世界规则与局部测试 |
| `src/worker/` | 世界状态写入、命令与持久化入口 |
| `src/ui/` | 游戏界面与操作流程 |
| `src/map/` | 正式地图、地图样板、模型与地理投影 |
| `src/data/` | 场景数据、稳定实体 ID 与资料来源 |
| `src/character/`、`src/city/` | 人物外观、城市展示及配套逻辑 |
| `public/art/`、`public/data/` | 运行时美术、模型与地理数据 |
| `art/` | Blender 源文件；与发布模型分别保留 |
| `scripts/`、`tests/` | 数据与美术生成脚本、资产验证；其他测试就近存放 |
| `docs/` | 专题设计、实施记录、数值审计与日志 |
| `chat/` | 外部设计输入；本地预览压缩包不提交 |
| `output/` | 已保留的美术方向样板与评估资料 |

`node_modules/`、`dist/`、`.cache/`、`.tmp/` 与 WorkBuddy 工作目录为本地产物，不提交。诊断日志、预览、截图放入已忽略目录；需要保留的源素材、来源说明和设计文档按对应目录归档。缓存中的实机验收证据不随日常整理自动删除。

## 存档与发布

本地存档使用 IndexedDB；线上入口为 <https://siegtrack.com/games/fengyun-nanbeichao/>，使用鲤世界账号及服务端存档。两处存档不会自动合并，可通过导出／导入迁移。本地运行不需要账号或 API 密钥。

部署构建参数为 `--base /games/fengyun-nanbeichao/`。创建分支／worktree、推送和公开部署均需明确授权；发布路径、原子切换及主页保护规则见 [AGENTS.md](AGENTS.md)。

## 资料与历史记录

地形使用真实地理数据，游戏数值、夸张比例模型与示意疆界不作为历史考据。第三方来源与许可见 [署名说明](public/THIRD_PARTY_NOTICES.md)，各美术目录保留各自来源说明。

原 README 中的开发过程、早期地图方案及验证记录完整保留在 [历史开发记录](docs/历史开发记录.md)。近期机制与界面状态以 [迭代整合进度](docs/迭代整合进度.md) 和相关专题记录为准。
