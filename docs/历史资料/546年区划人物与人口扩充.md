# 546 年区划、人物与人口扩充

本轮在现有三国剧本中增补可交互内容，同时维护行政实体、人物关系与人口口径。它不是全国州县全集或 546 年逐县普查复原。新开局使用新人口；旧局保留玩家已经改变的旧地点人口和库存。

## 覆盖范围与历史可信度

- 地图从 53 处扩至 **113 处**：梁 51、东魏 34、西魏 24、周边 4。新增 60 处县治／城堡锚点。行政树含 **50 个州级实体、72 个郡级实体、109 个县级实体**；周边 4 处保留未考定状态，不杜撰五级关系。
- 扩充重点：江南吴兴、钱唐、临海、永嘉与闽赣；江汉、湘南、岭南与巴蜀；河北清河、中山、信都和魏尹完整十三县；关中、河东玉壁、泾原与陇右。
- 主要依据：[《魏书·地形志上》](https://zh.wikisource.org/wiki/魏書/卷106上)、[中](https://zh.wikisource.org/wiki/魏書/卷106中)、[下](https://zh.wikisource.org/wiki/魏書/卷106下)，[《南齐书·州郡上》](https://zh.wikisource.org/wiki/南齊書/卷14)、[下](https://zh.wikisource.org/wiki/南齊書/卷15)，[《梁书·武帝纪下》](https://zh.wikisource.org/wiki/梁書/卷03)、[《隋书·地理下》](https://zh.wikisource.org/wiki/隋書/卷31)的沿革追述；玉壁参见[《周书·韦孝宽传》](https://zh.wikisource.org/wiki/周書/卷31)。
- 梁与西魏部分州郡隶属仍是较早地志及后代追述的工作性推定，个别置废年份须进一步逐条考订；记录保留 `earlier-source` 和提示。不能把数据收录等同于完成学术审定。
- 所有地点用稳定 ID；道路连接不充当行政父级。新增地块沿用离线陆地裁切的交互分区，**不是史籍县界，也不支持据此推断精确历史疆域**。地图原有真实地形来源不变。
- 州名、郡名、县治分缩放层显示；同郡县治列表合并实际已录地点及尚未定位的史籍县名，未定位者不可进入。

生平来源分条保存在 `expandedPeople.ts`。新增人物出生年暂统一标为估计值，即便其中部分年份可据史书年龄反推，也不伪装成已完成逐人生日考订。驻地是剧本锚点；性格、能力、面容组合是玩法／美术设定，不是历史测量。未提前设置侯景叛梁、庾信北迁、隋唐建朝或独孤伽罗与杨坚婚姻。

- 补入萧统、韦叡、韦放、王神念等已故先人；陈道谭在 546 年仍活着，不因其是父辈就归入死者。
- 扩展萧、高、宇文、独孤、韦、徐、庾、斛律、苏、于、李等家系及父子关系。清河崔氏与博陵崔氏、陇西李氏与辽东李氏分别建模；同一家族内未证实的支系不强接共同祖先。
- 崔㥄、崔瞻从只读族谱资料接入实际交往、任职和威望。各族有姓氏族徽、籍贯／郡望记录；新成员贡献进入原有世族排行。
- 架空沈、韩、陆家系有独立 ID，仅互连架空亲属，不附会真实望族。初始婚姻未知与确实未婚保持区别。
- 新人物复用已验收的线描淡彩五官组合与角色边框，不新增一套肖像框架。补齐新增儿童使用幼年底稿，成年后按年龄与职务切换。
- 本轮新增人物作为世界 NPC 接入查找、城市人物、交往、幕府、官职和公共继承。**开局可扮演与私人家业交接仍为原有 11 位角色范围**；没有宣称开放所有新人物开局或实现生育。

## 人口估计方法

统计对象为“县治及其农业腹地常住人口”，不是城墙内人口；地图上未收录的县不能算进本版人口总和。本版总和不是三国全国人口。

1. **有郡级数目的地区**：魏尹十三县合计 438,024 口，采用《魏书》武定时期郡级记载作为约束。地图已录十三县，以邺权重 6、临漳 2、其他县各 1 分配；最后一县补齐取整尾差，合计严格一致。县值均为推算，不冒充史书逐县数据。上下区间按 ±30% 提示分配不确定性，不是统计置信区间。
2. **缺少同年县级数目的地区**：按都邑地位、农耕环境、区域交通、战乱后的相对规模设置。建康及腹地 18 万、长安 8.5 万、成都 8.2 万、江陵 7 万；衰落后的洛阳 2.8 万；敦煌 8 千。新增普通县按地区初值再受山地／绿洲折减。范围 ±40%，全部明确为区域推定。引用地志支持区域背景，**不代表地志载有这些数字**。
3. 初值与区间逐点保存于 `populationEstimates.ts`。城市人口悬停可查看初值、口径、估计方式与范围。游戏推进后的当前人口仍来自迁徙、征募、伤亡、饥荒与增长，不被历史初值覆盖。

## 跨模块适配

| 模块 | 调整及边界 |
| --- | --- |
| 地方经济 | 人口继续进入产粮、民食、税收、行政支出；耕地承载随新增县域初始规模设定，避免用几千人的旧承载量套到数万人的县。承载是游戏参数，不是耕地史料测量。 |
| 公共财政 | 新地点沿州郡县实体进入逐级上缴、拨款；不另建钱包。大县税基更高，同时民食、行政和储粮需求更大。 |
| 政治集团 | 新增成年人按背景进入既有集团；未成年人不贡献政治力量、不成为领袖。人口税基权重改为万人量级，避免所有大县刺史立即顶满旧上限。平稳府库和秩序的缓和作用不会因出现轻微集团不满而全部消失。 |
| 任职、移动、幕府 | 新人物复用任职条件、真实赴任、俸禄、考绩和延聘；派员与统帅名单移除“仅开局角色”限制，未成年不可承办。 |
| 差事 | 合格玩家仍能收到 NPC 协办邀请，不因新名录排列在前而永远被挤出；邀请仍须接受，不自动决定。 |
| 家族、继承、健康 | 新成员计入声望；有出处的父子边参与公共继承排序，可指定新成年人物；继位后的政权存档认可这些人物；同族延医覆盖新增成员。私人可玩家业继承范围未扩大。 |
| 性能 | 预索引家族成员，集团排名一次计算各人成分，避免排序比较器反复扫描领地。几十年全世界测试使用专项较长时限，不扩大普通测试的时限。 |
| 存档 | 地图内容版本 0.1 → 0.2，一次性追加升级。已有城市人口／粮食／钱款／关系／任务不重置；新增地方以剧本状态登记，新人物私人余额和威望从零开始，不补发往期收益。多年旧局新增地方仍用原始名录与归属，不能推断旧局未模拟地区的历史变化；想体验完整 546 基底建议新开局。 |

## 验证与验收

本轮 53 个测试文件、481 项测试全部通过，生产构建通过；保留已有分包体积提醒。

自动验证覆盖：地点唯一与道路连通、五级父子关系、郡人口不重复、估计区间与承载、未成年任职限制、真实赴任、家系无环、继承后保存、旧档资源保留与迁移幂等、损坏数据拒绝；保留已有多年结算和分段回放测试。

UI 仅供用户人工验收：地图缩放与区划导航；搜索徐陵、斛律光、韦孝宽；查看徐氏／韦氏／苏氏族谱；比对建康、洛阳、敦煌的人口详情；任命新增人物观察赴任。未进行自动化浏览器或截图验收，未部署线上。
