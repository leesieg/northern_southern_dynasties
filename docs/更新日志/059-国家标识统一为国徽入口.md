# 更新日志 059｜国家标识统一为国徽入口

更新日期：2026-09-24

## 本轮变化

- 人物、政务、制度、官职、差事、局势、城邑军务、继承、外交条约与使团中的结构化国家标识统一使用现有政权徽旗，点击进入对应国家详情。
- 名称放入悬停提示和可访问标签，去除国徽旁重复的国名；外交本国、宗主、条约双方及宣战对象均提供关联入口。
- 人物和城市查询结果将国徽与对象入口分为独立按钮，避免误触。筛选、行政辖区切换、出使目标选择与国家详情入口各自保留，不让一个按钮承担两种动作。
- 事件弹窗可通过国徽进入详情，沿用现有导航方式关闭当前通知，实际待决事务不因此作出裁决。
- 历史国号保留原名称用于徽旗及提示；新国号输入、人物官号、叙事正文及必要说明不进行不可靠的字符串替换。周边地区无统一国家档案，标识禁用并说明原因。

## 验证

439 项测试、50 个测试文件通过，生产构建通过，保留既有大分包提示。未改存档或游戏结算逻辑；国徽跳转、返回与列表点击区待人工验收，未做浏览器自动化验收。未推送或部署。
