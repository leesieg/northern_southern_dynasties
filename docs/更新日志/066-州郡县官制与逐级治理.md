# 开发日志 066 - 从一县到一州

地方官现在有了完整的行政上下级。管理县城的人不再一律叫刺史：县官经营一县，太守协调属县，刺史统筹属郡。地图中的县与县城打开同一张详情，建设和出行仍围绕具体城市展开。

## 任命，还是举荐

皇帝和有实权的执政者可以直接授官，也可以将辖下授官权交给州郡主官。没有授权时，地方官可以举荐或请任，等待上级批复。越级任命不会使县令绕开太守成为中央直属；越级撤换现任还会影响上级关系和朝野支持。

授官要支付影响力，还要等文书送达和本人赴任。空缺可以暂时代行，但 90 日后必须重新处理。正式授官可兼领地方原职，至多三项；兼任越多，统筹效率越低。确认前可以比较候选人的能力、功绩和政治条件，功绩不足的破格任命也有代价。

## 上级的钱在哪里

县收税后留用一部分，余款经郡、州上缴中央。每级留下的资金属于该级公库，不是上级人物的私人财产。县令请款找太守，太守不足可以向刺史申请。批准下级请求会真正减少审批者管理的那份公款，不再自动从中央取钱。

中央专项拨款与原有全国公务仍然保留。地方任职、考绩和集团实力已经接入同一套人物机制；NPC 也会争取空缺。晋升会扩大权责，同时带来更多下属和预算选择。

## 存档与验收

旧城主按县级职务保留，不自动升为刺史；人口、钱粮、建设和任务不重置。县城重复账户合并时保留资金和流水，无法无损合并的极限容量情况会明确报错。

完整规则及边界见[地方官制与县域治理](../机制设计/地方官制与县域治理.md)。全量 54 个测试文件、498 项测试通过；最后的改朝权限与界面收尾后，65 项定向回归通过，生产构建通过。数值声明清单更新为 287 项；保留原有分包体积提醒。界面需人工验收，未推送或部署。

## 界面补充：州郡县统一详情

州、郡沿用县域的身份栏、主官席位、六项图标指标与六个操作页签。公款显示本级余额，公粮和人口为实际控制县域合计，秩序与繁荣按人口加权；悬停说明统计口径。城景、营建、出行从辖下县域进入对应操作，人物集中在人物页签，区划展示直属辖区。

三个层级共用路径与同级导航；切换保留页签、返回链和各页滚动位置，抽屉外框不再随地点重建。仅改前端展示与导航，未修改核心规则或存档。按本次要求不运行测试；编译和生产构建通过，视觉与操作待人工验收。
