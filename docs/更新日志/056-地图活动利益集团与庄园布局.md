# 更新日志 056｜地图活动、利益集团与庄园布局

更新日期：2026-09-24

## 地图上的重要事项

玩家相关的驻留活动、地方差事、城市与庄园营建在地图上出现图标徽记，同城事项聚合。点击徽记查看事项状态、实际进度和期限，再进入对应办理页面。完成或取消的事项自动移除；普通行旅沿用现有人物移动标记，私人计谋不新增地图标记。

## 利益集团与局势

利益集团从朝廷移至局势右侧抽屉。王朝兴衰、利益集团、纪事分别使用图标页签；兴衰页以墨绿、旧金、朱红的半圆仪盘表达安定、动荡与危局，并列出下期局势推力和现行经济军事效果。

集团势力仍来自真实成员的功绩、官职、辖城、家族声望、特质和清议。新增派别满意度：国策、朝廷眷顾、中央席位代表性、君主合法性、官场积弊和战争立场共同影响。悬停可查看逐项来源；未结党及空集团不产生压力。

每 30 日按集团势力与满意度结算紧张度和朝野支持，进一步影响既有税收、军饷、攻击、改革暂停与拥立条件。满意度低于 40、势力至少 25% 的非玩家领袖可主动上奏，沿用 90 日奏议冷却及 15 日裁决期限。执政玩家收到暂停决策弹窗；批准、否决与逾期结果使用既有规则。满意度是实时推导值，不另存第二份集团状态。

集团页集中展示领袖与成员头像、势力份额、满意度和每期影响；加入、眷顾、清议、奏议与游说保持真实成本及权限，游说使用人物选择弹窗。

## 庄园窗口

移除重复标题和全量建筑卡片。左侧保留随营建变化的庄园画面与全部建筑入口，右侧仅显示当前建筑效果、等级、费用、工期与营建操作；家事独立页签。顶部展示家族、地点、个人钱和建筑位。桌面采用一屏双栏，小窗口保留侧栏滚动，极窄屏回退纵向布局。

## 验证与边界

50 个测试文件、439 项测试通过，生产构建通过；保留既有大分包提示。新增规则覆盖集团诉求、代表性、月度结算幂等、政体暂停、自动奏议、决策通知、存档往返、地图聚合和取消移除。历史改朝换代测试显式准备安定朝局，避免把新增派系危局当成继承流程失败。

集团数值为游戏设计，不是历史人物立场考据。复用既有庄园图与图标素材，局势仪盘为原创矢量界面，未引入参考游戏图片。未进行自动化 UI 验收，地图标记密度、肖像裁切、庄园一屏布局待用户人工确认。未推送或部署。
