## 所在政权改朝换代通知（2026-10-03）

所在政权实际新增国统沿革时自动暂停，优先弹出改朝换代通知。触发依据当前人物的真实效忠，以及带前朝 ID 的新政治／异姓承统记录；支持政治交接、新朝内战胜出、君主身后异姓承统。人物身在国外仍按效忠政权判断，普通君位继承、仅改执政、外国易代、未完成议案及开局／读档不误报。旧朝、新朝、日期、君主及执政者保留发生时的快照；前任君主按交接前实际在位者取值，不误用开局君主。

样式参照用户提供的《全面战争：三国》事件截图：纸色左侧正文和国旗对照、右侧墨刷边缘朝堂与新君肖像、下方深色交接结果。使用现有朝堂画、肖像、国旗及墨刷资源，没有复制截图图片；沿用墨绿／旧金／纸色。通知只留一个“知道了”，支持 Escape 与焦点返回，内容可局部滚动，确认固定可见；关闭只移除本条消息，时间仍暂停，同日其他消息继续依次展示。

复用已有 worker 保存与暂停链：手动命令或加速推进提交世界成功后通知，保存失败回滚至旧世界，未提交结果不入队。同一沿革 ID 不重复通知，读档以现状为基线；通知队列沿用临时事件模式，不另存未读状态，不修改原交接、家产、官职、钱粮、军队及条约结算。

验证：9 个局部用例通过（7 个沿革通知规则用例，2 个 worker 命令／加速推进用例），覆盖政治易代、内战结算、异姓承统与家业继承并发、实际效忠、异地停留、前任君主变动、普通交接排除、只读快照、存读与重复通知，以及两条执行路径的保存失败回滚。生产构建、差异检查通过，数值声明索引重建为 705 项；没有 UI 自动化、截图比对、长局或完整游戏回归。

人工验收入口 http://127.0.0.1:5173/：沙盒中所在政权的权力更替议案完成、内战易代或异姓承统后，检查暂停当天、旧／新国旗与人物信息、纸面／配图／底栏布局、长文本滚动、知道了／Escape／焦点返回、多条消息及关闭后保持暂停。未推送或部署。
