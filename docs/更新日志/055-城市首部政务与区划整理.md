# 更新日志 055｜城市首部、政务与区划整理

更新日期：2026-09-24

## 本轮变化

- 城市名称、政权旗帜、刺史半身像席位和资源集中到紧凑首部；点击旗帜进入国家详情。城市治理职位统一称为“刺史”，沿用已有任命和申请规则。
- 本城公款展示本期留存账目的实际净收支；中央公粮展示上期预算变化；刺史影响力展示例行增长。职位空缺时不虚构影响力。
- 治理与军务合并为“政务”：民政税策、地方公务、军务行动和财政申请按用途分组。税策标出现行状态，行动采用图标卡片，不可用原因通过悬停或键盘聚焦查看，宣战、议和与遣散保留确认。
- 巡察安抚仅保留在城市政务的地方公务区，出行页不再重复。中央公务委派仍可从地方公务进入。
- 区划改为政权、州、郡、县、城市逐级入口及同郡县治卡片；已定位城市可进入，未定位地点标记并禁用。
- 城市页签改为紧凑图标与短标题，保留旧军务入口跳转兼容。

## 状态与边界

432 项测试、48 个测试文件通过；生产构建通过，仍有既有分包超过 500 kB 的提示。未进行浏览器自动化验收，视觉与操作待用户人工验收；未部署或推送。

本轮调整展示和交互，不更改财政、权限与战争结算规则。公粮仍是控制政权的中央库存，影响力属于刺史本人；公款流水并非收入预测。区划依据 546 年资料基底，不将城市易手推断为州郡疆域整体转移。“刺史”是本作统一职位显示名，不表示每一城的历史行政长官均称刺史。
