# 更新日志 053｜中央公务城市领主与个人能力

更新日期：2026-09-24　整理日期：2026-09-24

## 本轮变化

- 君主只保留中央官职，官员可受委派或自行立项办理城建、水利、征募和征税。
- 城市首部展示领主席位，复用任命／申请交互。
- 人物集中展示外交、军事、管理、谋略与影响力、功绩、威望，能力来源可悬停查阅。
- 能力进入实际报价、接受度与公务效率，影响力随人物积累而不随家业继承。

## 状态与边界

418 项测试与构建通过是当轮记录；视觉与操作待人工验收。大型水利以城市实际指标和结果记录体现。
