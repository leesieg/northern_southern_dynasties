## 核对结果与实现

- [x] **地方优先支付、中央补差。** 原有地方留用税与中央全额负担重叠的问题得到确认。地方行政及州郡官俸先用自己的公库，中央只补实际缺口；预算预测复用同一支付次序，城市秩序依据已支付的行政费用变化。跨国纯转移同时记录来源和收款国，避免再被中央收支对账重复登记。
- [x] **粮食口径与基础生存。** 原日军粮和月民食确有尺度偏差。采用同一公粮单位，军需按人日计入 50% 供养负担，600 人、30 日、无修正时消耗 6 粮；零头累积后记整粮，断粮不能由当日未满一粮掩盖。预算采用相同累计公式做 30 日军粮折算。都城民食缺口可真实动用中央粮仓；新局地方有两个月基础民食，旧档不补发粮。NPC 可按真实余额、运力、道路与权限调粮和赈济。
- [x] **局势压力与恢复。** 集团紧张和支持先合并再取整，少数集团不再各扣整数。静态集团分歧只推动到受限基线；都城失守冲击只结算一次，持续后果来自真实地方失序、民食、预算、欠饷及履职情况。平稳财政、民食或监察可各自带来恢复，保留原有阶段迟滞。玩家待决事件不会阻断其他国家正常任官。
- [x] **国家战略。** NPC 按月判断边境动机、真实控制道路、条约／停战、地方兵力、训练、统帅、粮储和两个月出征预算；先筹备再宣战，复用明确行动者的公共宣战入口。默认自动战略指挥，显式手动军队保留玩家控制；NPC 具名统帅实际赴营，出征保留防守军。有限目标达成或续战收益不足时议和，随后休整三个月；遇玩家朝廷只提出十五日有效的和约，由玩家接受或拒绝。
- [x] **全人物拘押。** 野战溃散依据当前统帅与真实参战位置一次结算，被俘、脱离或阵亡写入战报；保存独立人物命运，历史列表裁剪不重新抽取。同城强攻只处理实际在场的官员等关键人物；协商议降可沿真实安全道路撤离，无道路则保留为自由人物。移除军队或驻地变国不会凭空造俘虏。
- [x] **处置与招降。** 严押、礼遇、软禁有真实月费与脱困取舍；释放、赎回、换俘、处决依当前看管与国家裁定权限办理，内战按实际俘获阵营判断。赎金进入俘获方中央，本人／亲族／旧国公款按真实钱包与同意条件支付；玩家执政者的账户不能被请求方代批。招降依据交情、旧主忠诚、待遇、处境、性格及游说者，条件未变不能反复抽结果。授职承诺更能打动人物，但九十日内未兑现会损伤关系与忠诚。
- [x] **身份、资产与后续。** 被拘押不改效忠、家产、合法官职或君位，但暂停行动、任官、统军和治理能力。临时代理复用自由的现有人物，释放后恢复原执政格局。招降只改变本人，交接旧职；原部队、地方公款与追随者不随之变国，旧幕府欠俸保留为债权。被俘使者使命明确中止；战役统帅失能时结余退原账户，不继续操纵原军。死亡与处决走公共婚姻、官职、继承清理。
- [x] **国内案件与围城选择。** 拘捕需要控制所在地并等待七日执行，依据已核实侵吞、叛乱或拒命记录；无案由拘捕损伤支持与关系，边将可拒捕并按既有条件举兵。释案、罚赎、百钱担保及九十日守约返还／再犯没收都有结算；本国案件不能靠反复招降刷礼金，NPC 朝廷也会审理玩家案件。守城主官实际在城才可坚守、突围或议降，突围使用真实道路和所统驻军，失败本人可能被俘。
- [x] **交互。** 现有人物详情、军事页、朝廷地方页、战争窗口及暂停事件复用游戏现行组件。新处置以人物肖像为中心，提供并列处置、待遇和关系因子，参考《全面战争：三国》的关系与人物经营思路；不复刻其数值或素材。选人与草稿用既有弹窗、搜索、排序和真正单选，确认前重新校验，固定确认／取消区；对象切换清理草稿。处决明确不可撤销，战报人物可直达本人处置。
