# 061 · 人口经济与治理闭环

日期：2026-09-24

本轮处理“有名册却不能任官、城市价值趋同、集团缺少行动影响、差事缺乏选择”的问题，并按用户追加要求将地方社会建立在人口之上。完整设计及实际参数见[治理体系优化方案](../治理体系优化方案.md)。

## 玩家可见变化

- 城市政务展示人口、产粮、民食、本地公粮和区域效率；城市头部公粮改为本城储备，悬停区分产出、民食及损耗前净值。人口、地利、商路、水利、劳力占用、刺史管理及生活重心共同决定产出；城仓增加储量、降低保管损耗。
- 城市提供安置迁民、强制迁徙、战时掠夺与运粮。出发前可见人数、费用、天数、损耗；道路失控暂停，撤回有返程与额外损耗。顶部事项旗直达城市，抵达后给出接收和损耗通知。掠夺要求交战、驻军和占领，付出政治及外交代价。
- 动员与补员扣除当地人口，遣散返还存活者。军粮实际从中央/地方库存扣除，运输沿道路推进，抵达才补充部队。为使远征和围城可维持，随军粮容量改为 600，并重新配平日耗粮；NPC 使用相同补给规则。
- 刺史及中央官职候选人接入完整的已登记关系人物。陈霸先可受任广州刺史，文书送达且本人抵达后才获得治理权；现有公务须先交接。低功绩破格任命会引起政治代价，受权臣控制的君主还需实际执政者支持。
- 君主不再显示加入普通集团的入口。集团展示成员实力来源及国政立场，任官、改革、税收、军务、迁民等影响支持与局势，相关差事效率随政治阻力变化。
- 差事首先展示依据真实地方状态排序的推荐及理由。三种方案体现钱、时间和质量取舍；中途加钱、协商、强令有不同代价，不能花钱直接解除封锁与严重失序。大工程按规模核定限期，可由执政者批准一次延期。
- 结案展示完成程度、支出、退回专款、时效、质量与实际收益。累计支出不会因增加工作量倒退；取消结算未用资金，保留部分已完成民政成果，重复结案不会重复奖励。

## 存档与验证

- 户数旧字段只用于兼容迁移，按每户 5 人转换一次；不赠送额外公款或粮储。人口、在途队伍、军粮运输、延期、耗用与质量进入存档校验。
- 新增人口随生产变化、城仓不制造粮食、迁徙守恒和损耗、受阻返还、非法掠夺、陈霸先实际赴任、君主身份、集团来源与行动效率、差事退款/延期、旧档幂等迁移及坏档拒绝测试。
- 457 项测试、51 个测试文件全部通过；生产构建通过。保留原有大包体提示。未执行 UI 自动化，视觉与操作待人工验收。
- 本轮为本地版本，未推送、未公开部署。人口与经济参数是策略模拟规模，不声称是 546 年真实户籍或产量。

## 人工验收

以萧衍新局进入广州，任命陈霸先；观察文书、赴任和履职。比较都城、商贸节点与山地城市，组织迁民和调粮，查看队伍进度及接收明细。局势页检查集团来源与政策立场，差事簿检查推荐、方案、延期和考绩。掠夺需先完成宣战与占领，不在和平状态开放。
