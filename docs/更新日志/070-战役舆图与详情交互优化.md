# 070 · 战役舆图与详情交互优化

日期：2026-09-30。状态：本地实现与非 UI 检查完成，界面待人工验收，未部署或推送。

## 玩家可见变化

- 地图按缩放在青绿山川和纸色舆图间渐变：缩放级别 4.8 以下使用纸色水陆、墨线与纸纹，缩放结束后铺平视角并关闭地形隆起；6.2 以上恢复近景高程着色。关闭“立体山河”仍可使用平面近景。使用原有真实高程和水系，不新增虚构地理。
- 城邑改为带控制方色边的紧凑名牌；都城加强顶边与字级。城市避让依据标签长度及实际宽度。选中与键盘聚焦有明确反馈。
- 远景军队使用更小的纸色军旗卡，卡片尺寸、点击范围和避让计算一致。近景保留原有 3D 兵模、实际经纬度与同地代表机制，不通过移动兵模避让。庄园、在途人物及事务统一金边墨绿；远景仅保留玩家的行旅标记，其他在途人物拉近可见。真实事务和军队不因远景被整体关闭。
- 右下角按朝廷／朝局、视角、地图模式、显示设置组织。新增直达本国朝廷入口；军队模型、动画、在途人物、立体山河集中于带开关状态的显示面板。说明支持悬停和键盘聚焦；Escape 优先收起显示面板并返回触发按钮。
- 左侧人物、政务、军事、经济、国家外交、查找、存档、指南与地方详情复用绘画题头、紧凑页签、旧金边框。复用项目现有朝堂、庄园与山河画，不占用额外大图区域。保留现有身份摘要、主操作和页签结构。
- 城市首次进入默认民政，州郡对应统筹；旧教学局进入区划信息。城景依旧有独立入口。地图路线提示改为“左侧出行页”。关闭主抽屉尝试返回原触发元素；原元素已移除时不强行定位。
- 人物国徽及查找“同朝”使用当前效忠关系，不再仅取开局国家。
- 经济页捐输、侵吞分别打开行动弹窗，在弹窗内选公库、金额和确认。明确私财、公款流向；确认时再次调用现有规则校验，不能使用已失去权限的公库。

## 人工验收入口

[本地游戏](http://127.0.0.1:5173/)

1. 全国缩小查看纸色、国号及军旗卡；拉近验证山川、城市名和兵模衔接，测试“立体山河”开关。
2. 在军队、城市、庄园与事务重叠区域检查标签遮挡、点选、缩放和移动；查看军旗卡与兵模是否始终对应同一位置。
3. 依次打开左侧人物、政务、军事、经济、外交、查找和地方详情，检查题头、首屏操作、长名单滚动、返回与关闭。
4. 使用键盘进入右下角各入口，检查说明、选中反馈和 Escape；从经济页打开捐输弹窗修改目标与金额，取消不得扣款。
5. 检查 1366×768 与较窄桌面视口下，右下角工具、详情抽屉、顶部资源及军队列表是否互相遮挡。
