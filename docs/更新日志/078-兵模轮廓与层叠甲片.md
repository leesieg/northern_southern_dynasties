# 078 · 兵模轮廓与层叠甲片

## 改动

- 将椭球躯干与旋转体衣裙改为贴合人体的连续截面网格，收腰、扩肩，衣摆、袖管及裤腿带逐渐收束的褶皱。
- 胸背甲、甲裙和肩甲改为薄片叠层，带倒角、圆角下缘、错列与铆钉；皮带、挂带及佩刀提供材质与轮廓层次。甲片和铆钉各自使用实例批次，共享几何与材质。
- 增加盔眉铜饰和开放式后颈护甲；马身改为连续胸腹轮廓，保留现有骑乘、鞍具和动作。
- 长兵器绑定持握手臂，行军及战斗时随手移动，避免手臂运动而兵器留在原地。
- 保留真实驻地／在途坐标、模型显示尺寸、军旗及既有减少动态效果设置。原始模型由项目代码创建，没有引入商业游戏素材。

## 参考与边界

以《全面战争：三国》战役地图的写实轮廓、层叠装备为方向，参考[战役地图截图](https://main.judgehype.com/images/froala/2019/05/1559307279_6.jpg)。本次仍是实时程序化网格细化，不等同于商业游戏经过雕刻、烘焙和完整骨骼制作的角色资产，不能据代码检查宣称达到同等成品精度。

## 光影与肤色跟进（2026-09-30）

- 检查原始材质图发现布料、铁甲已有深色底与绘制阴影；全强度乘上底色及甲片实例色，会继续压暗。在线性空间将贴图颜色贡献降至 48%，保留纹理但减弱重复阴影；仍使用物理受光，不添加自发光。
- 天光、地面反射及环境补光减少黄绿偏色，加强反侧补光，略收敛主光。甲片实例色保持中性，减弱二次染色。
- 面部、手和颈部共用柔和暖肤色，嘴唇接近肤色，眉毛及虹膜减淡，眼白去除偏黄底色。保留现有面部结构与表面受光。
- 验证：构建通过；`militaryPresentation.test.ts`、`militaryFace.test.ts`、`militaryLayer.test.ts` 共 34 项通过；差异格式检查通过。已核对当前 Three 标准材质的贴图 shader 注入位置，但未执行 GPU shader 编译或 UI 自动化验收。
- 待人工验收：本地地图中检查不同朝向的脸部和甲胄，确认暗面可读、肤色自然且亮面不过曝。仅本地提交，未推送或部署。
