# 078 · 兵模轮廓与层叠甲片

## 改动

- 将椭球躯干与旋转体衣裙改为贴合人体的连续截面网格，收腰、扩肩，衣摆、袖管及裤腿带逐渐收束的褶皱。
- 胸背甲、甲裙和肩甲改为薄片叠层，带倒角、圆角下缘、错列与铆钉；皮带、挂带及佩刀提供材质与轮廓层次。甲片和铆钉各自使用实例批次，共享几何与材质。
- 增加盔眉铜饰和开放式后颈护甲；马身改为连续胸腹轮廓，保留现有骑乘、鞍具和动作。
- 长兵器绑定持握手臂，行军及战斗时随手移动，避免手臂运动而兵器留在原地。
- 保留真实驻地／在途坐标、模型显示尺寸、军旗及既有减少动态效果设置。原始模型由项目代码创建，没有引入商业游戏素材。

## 参考与边界

以《全面战争：三国》战役地图的写实轮廓、层叠装备为方向，参考[战役地图截图](https://main.judgehype.com/images/froala/2019/05/1559307279_6.jpg)。本次仍是实时程序化网格细化，不等同于商业游戏经过雕刻、烘焙和完整骨骼制作的角色资产，不能据代码检查宣称达到同等成品精度。
