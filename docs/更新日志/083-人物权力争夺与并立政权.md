授权：2026-09-30，复核「南北朝机制评估」并实施值得做的优化。实际实施基线 `3467b63`，其国家战略、经济恢复与全人物拘押已作为本轮基础。引用评估原核对的 `64f24a9` 只作为问题线索，全部建议按当前代码重新确认。本地实施，不新建分支／worktree，不推送或部署；原有未跟踪的 `.workbuddy/` 和 `chat/` 资料保留。

## 核对与落地

- [x] **共同权力安排。** 历史受禅、沙盒建朝和政治内战共用更换执政、拥立君主、改朝换代三个目标；发起者、受益君主和实际执政者可以不同。流程为争取支持、公开呈请、接受或冲突，复用本人影响力、关系、誓约、家族、现任官位和实际追随兵团。支持是具体安排的派生表态，不把改革派自动当作篡位者的支持者，也不增加权臣值或政治货币。
- [x] **稳定朝廷可以和平更替。** 不再要求先降低合法性或制造危局。合法性进入反对因子；一国一个主要政治议程，有交涉期和恢复期，不能反复许诺刷支持。历史路线成为有年份和真实参与人约束的模板，北周允许宇文护推动宇文觉居君位并继续执政，梁末拥立与陈受禅也分开办理。旧九十日历史任务和一百二十日建朝任务兼容至结案，不撤销原已付成本。
- [x] **选择性承接。** 接受和观望者的有效公职继续，明确反对者离职。军队编制、兵源、经验、损耗、欠饷、钱粮、税基、外交条约、朝贡和债务保留；外交承认重新确认。建朝不自动改为天朝制，不清空国库、普遍扣全军士气或收回失地。主要执政交接只让少数有真实私人兵权且存在矛盾的将领要求确认待遇，普通官员继续履职。
- [x] **有条件的个人／携部归附。** 保留部曲、逐步改编、只接纳个人三个并列方案，经接纳国实际执政者裁定后办理。人物、兵团和地方归属分别结算；个人投奔不带走军队、城市或未响应的追随者。武装归附按真实兵团忠诚拆分人头、随军粮与耗粮零头，旧欠饷留原债务账户；接纳国承担保护预算、供饷与保护战争。背约依据拘押、撤兵权、实际欠饷产生交涉和关系／誓约后果，NPC 起兵仍须真实根据地、部队、钱粮和私财。改编保留兵团 ID、经验、原籍和个人忠诚。
- [x] **持续政治内战。** 内战可与外战并存，胜利按原定目标更换执政、拥立约定君主或建朝。实际敌我、行军、驻仓补给、围城、外援与支付使用本场阵营，外国援军不因旧国家标签获得对立地方的军政权限。结束一场内战只结清本场战争及围城，其他战场继续。对象死亡或改投会明确调整／终止安排，不复活人物。
- [x] **控制朝廷与地方抵抗分开。** 攻占朝廷只拘押实际在场人物，捕获君主接入既有控制关系，不取得全国军队和税收。自由的地方官与统帅可继续组织原朝廷抵抗。地方回应提供出兵、实际驻仓供粮、暂缓三种选择；暂缓不被当作叛国或自动停税。NPC 防御征募使用真实人口、公款与粮食，带训练期，不刷出历史叛军。
- [x] **有限并立政权和迁驻。** 长期内战双方同意割据时才生成独立身份，最多六个新增政权、九个总身份。只转入真实响应的城市、人物、职位及兵团，新中央钱粮从零开始；地方公库按实际辖地人口分割，源账户保留余款并记流水。原国债务、未响应追随者和外战延续；外战目标成为新国辖地时，由新国承接守方，原国可继续作为盟军参战。迁都要求实际执政者抵达本方控制的法理辖地并支付中央公款；旧路上的使者先完成原路，再从真实驻地续行。
- [x] **战争、身份与存档衔接。** 复用上一轮整补、筹备、有限目标、议和、休整战略，本轮将实际内战阵营及新政权接入统帅、工资、财政、征募、通行、外交、迁运、任职、族望和死亡继承。战果可转化为统帅军功与影响力。各国朝廷、人物归属、外交入口、军旗和地图国号使用当前身份；新国号不冒充新增历史边界。
- [x] **可操作交互。** 朝廷「朝会」集中权力议案、表态、待遇确认、接纳、救援、迁驻和割据入口；本人「互动」和实际军队办理归附。现有交互复用行动弹窗、选人肖像、悬停／聚焦禁用原因和固定确认区；新交互采用人物居中的关系与表态展示、并列方案和明确接受／拒绝，参考《全面战争：三国》。选项只修改草稿，执行前重核现状，对象变化清理草稿；待裁定事件没有“知道了”代替真实决定。

官方参考：[Total War: THREE KINGDOMS](https://asia.sega.com/totalwar-three-kingdoms/en/)。参考其人物关系、军政选择与战果联动；本作议案、割据和履約参数属于本作适配，不声称复刻全战原规则或素材。

五类历史局面分别由有限外战、高氏交接与受禅、宇文护／宇文觉分工、带部归附与控制皇帝、平乱军功与战后拥立争夺组合表达。没有“侯景必反”“侯景死亡后陈必代梁”或历史姓名专属必胜奖励；结果取决于当局人物与真实资源。不增加完整封臣制、自由拼装几十种条约、九锡资源条或独立天下正统值。

## 2026-09-30 固定开局失稳、战争空转与自动亲政修复

本地陆明徽开局的政治失稳来源是日常劝农被当作全国改革，启办与完成两次累积反对；军事空转来源是留守后野战兵力不足却不征募，以及出发部队被移出集结统计；自动亲政来源是摄政控制固定按月下降、AI 权力争夺又被实际权臣难以获得的功绩门槛挡住。

已按上述三条实际链路修正，同时增加 AI 付费争取政治支持和延后无把握呈请的判断。保持真实征募成本、兵力与行军、玩家控制权限、议案支持门槛及历史身份条件；不保证固定年份、固定人物必然换朝。

定向验证：同一新开局推进至第 181 日，东西魏均为稳定，紧张度均为 0（修复前分别为 92／99），摄政控制均为 82；单次开局轨迹不作为多年平衡结论。局部用例覆盖地方政治缩放及不重复扣分、征募成本、留守与整队出发、真实战役及围城、直接控制排除、稳定摄政、低功绩实际执政者的历史派系到换朝、AI 承诺付费与重复调用。旧关系测试改为主动呈请与裁决历史方案，失权测试明确丧失朝廷支持，不再把过日子视为交权条件。

旧存档继续可用，但不自动撤销旧规则下已发生的亲政、政治损失或战争结果；复验固定开局请新开陆明徽。UI 仍待用户人工验收，未进行浏览器自动化、多年长局或完整游戏回归；未推送或部署。实际使用技能：project-workflow、karpathy-guidelines。

## 2026-09-30 战略 AI 目标与停战优化

针对“梁很少宣战、总是东魏先手、战争容易无条件和平”的后续反馈，补齐战略层判断：

- 梁等各国都能依据关系为负的边境机会考虑扩张，不再只等敌意达到 40；按人口／繁荣收益、驻防与接近路线比较目标，维持合理的已准备目标，不强制特定国家开战。
- 和平征募也扣除留守、排除直接控制与另有任务的军队，并统一士气口径；修正同城目标驻军被寻路空值漏算。远方援军按响应距离折算，避免要求每场边境战争都压倒对方全国兵力。按月份轮转国家检查顺序。
- 移除半年白和快捷条件，将实际续战能力、近期胜利、有效围城和目标方向行军加入评估；前线机会有期限，长期僵持和资源耗尽仍能停战。阻止空条件“要求胜利”；侵攻力量确已失去作战能力且目标守住时，允许守方结束战争。
