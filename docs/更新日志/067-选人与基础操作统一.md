# 067 · 选人与基础操作统一

日期：2026-09-25。状态：本地实现，待人工验收，未发布。

选择人物应能找到剧本中已经登记的人，查看人物则应立刻辨认其身份。本轮将最初 11 人的选人白名单扩展到已登记剧本人物，复用地图、名单和搜索；架空人物在摘要中标明。人物沿用既有出生信息、家族、关系与肖像；新开放的沙盒人物不因居住地点自动取得县令职务。新增人物开局的社交存储校验同步适配，原有存档仍保留原来的字段与身份。

人物详情以图标显示已选生活重心及最高层级的有效职位，悬停查看名称；职位按君主、执政、中央职务、州、郡、县与荣衔排序，无公职时可展示幕府岗位。职位图标进入官职页，玩家生活重心图标进入生活重心界面。

主菜单和局内存档页均可删除指定存档，确认前说明不可撤销。删除不销毁正在游玩的世界，继续保存仍会生成新存档。本地删除使用 IndexedDB 事务；账号存档发送对应槽位的 DELETE 请求，服务端成功后才更新列表，错误明确反馈。线上删除接口未联调，也未修改或部署主页服务。

空格在非文字输入场景专用于暂停或继续时间，不再触发获得焦点的其他按钮；暂停决策与存档等锁定场景仍不允许推进时间。主菜单和结局页拦截空格的按钮默认行为。

通用提示与特质提示共用定位，按实际内容尺寸优先排在触发项侧面，空间不足时调整上下位置。提示不接收鼠标点击，离开、滚动或点击时消失，避免提示浮层截住操作。

按用户要求不运行测试；TypeScript 编译和生产构建通过，保留既有大分包提醒。主菜单选人开局、存读删档、职位图标、空格与悬停体验待人工验收；账号存档删除另待线上接口确认。
