# 079 · 城市营建建筑细化

- 城市屋顶由平面三角面改为四坡曲面，增加轻微起翘的檐角、瓦垄、屋脊和脊端饰；同一屋顶的瓦垄合并成一个网格，相同尺寸复用几何。
- 建筑增加圆柱、檐下承托梁、门板、格栅窗、墙脚线及两级入口台阶；基础方块复用单位几何，窗口格栅合并网格。
- 城墙增加基座与压顶；集市补斜篷、货盘与货物，粮仓增加通风格栅，驿舍增加院落铺地。沿用原有等级、地块和施工数据，不增加新玩法。
- 场景采用 ACES 色调映射，减少暖黄光偏色并调整阴影偏移，帮助屋檐与墙面保留层次。

验证：`npm run build` 通过（已有分包大小提示）；`src/city/model.test.ts`、`src/city/architecture.test.ts` 共 6 项通过，覆盖施工／升级、存档状态、点击射线、资源释放及四坡屋顶法线与瓦垄边界；`git diff --check` 通过。

人工验收入口：http://127.0.0.1:5173/ ，城市详情 → 营建。检查旋转／缩放时的屋顶、城墙、门窗细节，三类建筑及施工地块的点选，并确认多建筑场景流畅度。未进行 UI 自动化或 GPU 性能测量，不宣称视觉已验收。仅本地提交，未推送或部署。
