# 城市政务信息与行动统一

日期：2026-09-24

- 人口、秩序、繁荣与本城公款、公粮、刺史影响力统一放在城市基础信息区，采用一致的图标、数值和悬停／键盘聚焦说明。
- 删除民政与迁民区重复的产粮、民食、公粮等摘要；税收预测、行政支出、仓容、生产修正集中到对应基础指标的说明中，保留实际收支与预测的区别。
- 民政、军务、迁民类型、巡察等使用同一套双列紧凑行动卡片。行动成本与结果按需查看，选中态、禁用原因和危险操作确认保留；迁民参数及确认出发按步骤展示。
- 城市地方公务不再重复显示“当地事务”标题，其他页面的事务标题不变。未修改世界规则与存档。

验证：457 项测试（51 个文件）通过，生产构建通过（保留既有大包体提示）；界面布局与操作需用户在本地入口人工验收，不进行浏览器自动化。
