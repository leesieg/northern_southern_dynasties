# 060 · 交互归属与关联导航审查

日期：2026-09-24

按 AGENTS.md 对菜单与选人、地图及事项旗、人物与家族、政务与差事、城市营建、外交、局势、庄园和共用弹窗作代码层交互审查。本轮修正实际发现的信息归属、导航和展示问题，不改世界规则或存档格式。

## 玩家可见变化

- 本城差事归入城市“政务”，区划只保留地理与历史信息；普通差事簿与天水粮务用互斥图标页签展示，本季推荐直接显示。
- 城市、约见人物和庄园只展示对应范围的活动。人物自己的总览仍保留完整个人日程，顶部事项旗不变。
- 从查找、人物、政务进入城市后可以返回来源；返回恢复城市、辖区、人物、邦交目标及主要页签。关闭选人等原生弹窗不会同时关闭底层抽屉。
- 家族树、祖先后代、族人贡献、亲友效忠摘要、制度中的君主与考课人物补齐统一方形肖像；亲属、贡献和制度人物入口进入人物详情。族谱节点继续用于选择世系中心。
- 家族威望记录直接展示；取消辖区页多余的政权切换器及重复路径标题。制度页不重复父页面的国徽，君主兼任执政时只展示一次。
- 营建财政与修正长说明移到可悬停、键盘聚焦的报价说明中；工程效果、成本、工期、不可用原因和确认操作保留。移除地图底部已无用途的说明节点。

## 保留与边界

- 保留必要的史料、边界精度说明和少量已有次要历史折叠，不机械改写为新的多层菜单；外交仍无折叠区块。
- 城市参数、家族选择等实际对象参数保留选择器，人物任命继续使用肖像选人弹窗。
- 返回恢复主要页面上下文；页面内部滚动位置及组件局部筛选状态尚不持久化。
- 本轮未改绘画资产、财政计算、权限、保存格式，也未部署或推送。

- 优化前以 `cabd835` 保存前期城市、局势、庄园与国徽更新检查点。

- 单元测试与生产构建结果见更新日志索引；保留已有大分包提示。
- 未使用浏览器自动化。视觉、点击路径、弹窗与窗口尺寸适配由用户在本地入口人工验收。
