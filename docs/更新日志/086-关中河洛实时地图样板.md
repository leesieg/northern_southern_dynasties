# 086 · 关中河洛实时地图样板

2026-10-08。用户批准已展示的美术方向，要求植被适度简化，并授权落地样板。

## 可见变化

- 独立入口 `/map-sample.html`，沿用 MapLibre 真实高程与地图坐标，支持区域全景、长安、洛阳定位及俯视／立体切换。正式游戏入口保持现状。
- Blender MCP 输出北方城邑与低细节林木 GLB；长安、洛阳共用城邑原型。屋顶、城墙和木构分别着色并加入轻量表面纹理。
- 远景使用地理林地纹理，近景以最多 280 株实例化树木补充层次，单株 140 三角面。树木避让城邑、水域、道路及陡坡；不随刷新随机重排。
- 地理数据或模型失败时明确提示，保留城邑铭牌与地图操作。样板不加载存档、不推进世界，不修改机制或数值。

## 验证与边界

- 4 项非 UI 定向测试通过：地图样式、植被确定性及城邑排除、GLB 单场景完整性与三角面／材质预算。`npm run build` 与 `git diff --check` 通过；保留既有大包体提示。
- 页面、两项模型、在线矢量入口及高程瓦片的本地 HTTP 请求均返回 200。
- 前端画面、模型落地、缩放手感、植被疏密和实际帧率待用户人工验收；没有执行浏览器自动化、截图验收、全量或长局测试。
- 美术目标图不等于本次浏览器实机效果，是否符合已确认风格须以本地样板验收为准。未部署、未推送。

## 加载卡住反馈修正

- 用户反馈持续显示“地理数据加载中”、无法预览。中心区域实际矢量瓦片和高程瓦片均返回 200；此结果不代表浏览器渲染成功。
- 移除已隐藏图层对应的全国行政／规则数据源，只保留样板所需的 5 个地图源；模型刷新仅响应相关数据源完成事件。
- 状态更新从单独依赖全图 `idle` 改为实际高程采样和矢量源状态，15 秒未完成时标明等待项并提供重新加载；网络错误直接显示原因。
- 新增状态回归检查，5 项局部测试、生产构建和差异检查通过；用户刷新后复验预览恢复情况。

## 浏览器复现与根因修复

- 用户再次反馈空白，并明确授权本轮使用浏览器测试和优化。实机复现为只有底色与城邑模型，5 个地图源均未完成、渲染要素数为 0；关闭模型仍然空白。
- 真正根因是独立入口遗漏正式地图的 `maplibre-gl-worker.mjs?worker&url` 配置，瓦片下载成功不代表 Worker 完成地理数据处理。样板现显式设置 Worker URL 与 2 个工作线程；此前状态提示修正并未解决此根因。
- 修复后浏览器中 5 个源全部完成、区域视图可查询 235 个渲染要素，地形与水系可见。完成长安／洛阳定位、俯视／立体切换的实机检查，无控制台警告或错误。城邑定位缩放从 10.7 调至 11.8，便于查看模型。
- 临时诊断面板和隔离参数已移除。5 项局部测试及生产构建通过，未执行全量／长局测试；这次验证加载与操作恢复，不代表美术目标完全验收。

## 河洛局部场景与材质重做

- 用户否定上一版风格后，授权重做局部实时样板；保留正式游戏入口，默认改为以洛阳为前景、真实山势为远景的河洛视角。
- 增加运行时地表材质层：四区原创贴图实际加载到浏览器，林冠按矢量林地分布，灰岩材质按真实高程坡度混合，城郊田野为明确标注的美术布置。材质贴在原 MapLibre 地形上，消除试作独立网格与原地形交叉的碎面；视点不变时不重复生成。
- Blender MCP 重导出城邑，增加 24 处低层近郊建筑和静态绛色旗帜，修正运行时贴图颜色读取与照明。模型为 47,286 三角面、5 个材质批次；林木仍为单株 140 面、总预算 280，城外少量点景树木与真实林地树木共用预算。
- 调整远近城邑展示尺度、3.2 倍地形展示夸张、64° 山河视角及铭牌上移。仅美术与镜头参数，不修改任何世界资源或存档。
- 6 项局部测试、生产构建通过；浏览器实机检查了加载、河洛视角、洛阳近景和立体切换，无控制台错误。当前仍为美术样板，不声称已完全达到参考游戏或目标图的细节品质。未推送／部署。

## 完整三维战役场景重建（替代以上样板实现）

- 用户明确纠正“重新做游戏地图，而非现有地图贴材质”，并于 2026-10-08 授权解除 MapLibre 架构限制。项目规则记录本专项例外；仍遵守先样板、用户确认后接入正式游戏。
- 样板入口改为独立 Three.js 场景，移除旧 MapLibre 样板代码及其专用资产。正式 `WorldMap`、规则、存档和城市 ID 不变。
- Blender MCP 从 24 张真实 Terrarium z8 瓦片重建关中河洛 296,065 顶点地形；原创城邑 37,046 三角面，含城门、角楼、院落街巷、曲面瓦顶及重檐主殿。三类林木 332／332／76 面，区域预算 18,000 实例，按小簇疏布。
- 全部资源本地化，首次真实绘制后才报告就绪；资源超时、HTTP 错误、渲染失败与 WebGL 上下文丢失都有明确反馈与重载入口。支持左键平移、右键旋转、滚轮／按钮缩放、方向键／Q/E 镜头操作，以及长安、洛阳、区域全览。
- 新增投影阴影、岩面光照细节、距离雾和少量谷雾。田块直接融入三维地表材质，避免贴地独立薄片的穿插碎面；河流沿真实 DEM 谷地有限贴合、平滑并开浅槽。城址平整、10 倍高程与河宽夸张均为美术展示，原始米制高程另存。现代水系与原创田地、林地布局不宣称历史复原。
- 10 项定向测试通过：经纬度往返、北到南高程插值与边界、河段距离、完整高程和河流资源、6 个 GLB 的完整性和面数预算。`npm run build` 通过，保留既有大包体提示。未运行全量或长局测试。
- 沿用用户对本专项的浏览器测试授权，实机验证本地载入、长安／洛阳切换、全览、旋转和缩放，并检查桌面与窄面板布局，无控制台错误。浏览器验证不等于风格验收；目前是关中河洛区域样板，未覆盖全国，也未接入军队、领土和正式存档。与目标图的艺术品质及植被密度仍待用户确认，不声称达到参考游戏成品质量。
- 1440×900 桌面视口的约 0.9 秒城邑镜头过渡，页面计数约 80.4 帧/秒；这是当前设备的短操作观测，不是长时间 GPU 基准或全国地图性能承诺。静止镜头的旗帜动画限约 15 帧/秒，阴影只在镜头变动时重算；减少动态效果模式下仅按需绘制。临时桌面视口已恢复，实机截图保存在本地可视化目录。

## 配色与风格细化

- 用户认可三维方向，要求颜色与样式进一步靠近《全面战争：三国》。本轮保持真实地形与镜头架构，压低草地黄绿饱和度，加入灰褐裸土过渡，强化深绿林冠、灰褐岩壁和局部金黄农田的区分；暖侧光配冷灰远雾。
- Blender MCP 更新青灰瓦、暖灰石墙、灰米色抹墙及林木材质，为城邑添加顶点风化色，不增加模型三角面和植被预算。原始地形资产保持不变。
- 水面增加细微纹理和浅岸过渡；田块边缘略作不规则化；旗帜补织物纹理，城邑铭牌调整纸色、墨字和旗尾，工具沿用墨绿旧金。仅美术展示，无游戏数值变化。
- 10 项原有定向测试、生产构建与差异检查通过。浏览器验证了实际加载、长安／洛阳视角和新材质，无控制台错误；风格最终由用户验收，仍未接入正式游戏、未部署或推送。

## 城邑模型、国家旗帜与横向名牌

- 按用户要求继续优化城邑。样板旗帜复用正式游戏 `armyHeraldry` / `RealmFlag`，从 `siteById` 的开局归属取国家：长安为西魏、洛阳为东魏；保持旗帜原比例、透明旗尾和纹章，移除样板自绘国号旗。挂旗顶部固定，布面底部轻摆。
- 名牌按参考游戏的横向城邑栏结构重做：圆形城邑徽记、墨绿底、旧金边、城市名与所属国家，位于城邑前方；使用项目原创 SVG/CSS，未提取参考游戏资产，不添加模拟之外的资源数值。修正横向 flex 样式覆盖 hidden、导致视野外名牌残留左上角的问题。
- Blender MCP 增加门墩和门额承托、重檐门楼、门窗木构、墙体扶壁、城墙步道、宫城低墙及台阶。城邑模型 39,954 三角面，仍低于 50,000 面预算；其余地形、岩石、植被资产不变。
- 10 项定向测试及生产构建通过，浏览器检查实际旗帜、名牌隐藏和城邑切换，无控制台报错。仍为待用户视觉验收的独立样板，未替换正式游戏、未部署或推送。

## 营建驱动的动态城市模型

- 在独立地图样板加入「营建样板」入口，也可点击城内三个地块选择市肆、城仓、驿舍。长安与洛阳分别保存本次演示的建筑等级和工程，刷新或重置后恢复；不接入正式存档。
- 复用 `core/construction` 的实际报价、扣款、工期、同城单工程限制、完工与三级上限。独立教学局初始演示资金为 2000 钱；推进日期同时沿用该模块的月度收入结算，不代表正式世界完整日结。
- Blender MCP 生成九个建筑等级模块与三个施工阶段模块。地块随进度展示地基、主体、屋面；升级期间保留现有建筑并叠加脚手架，完工后更新等级模型。静态城邑腾出营建区，基础模型降至 29,394 三角面；城墙、人口密度与战损尚未动态化。
- 24 项局部测试通过，覆盖真实扣款、重复开建限制、进度阶段、完成和升级、城市隔离、资金不足、等级上限、日期边界以及资产完整性和预算。生产构建通过，保留既有大包体提示；未执行全量或长局回归。
- 本轮操作检查覆盖开建、推进、完工、升级和地块选择；最终模型外观、地块布局及窄屏操作由用户人工验收。未替换正式地图、未部署或推送。
