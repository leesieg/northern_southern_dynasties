# 086 · 关中河洛实时地图样板

2026-10-08。用户批准已展示的美术方向，要求植被适度简化，并授权落地样板。

## 可见变化

- 独立入口 `/map-sample.html`，沿用 MapLibre 真实高程与地图坐标，支持区域全景、长安、洛阳定位及俯视／立体切换。正式游戏入口保持现状。
- Blender MCP 输出北方城邑与低细节林木 GLB；长安、洛阳共用城邑原型。屋顶、城墙和木构分别着色并加入轻量表面纹理。
- 远景使用地理林地纹理，近景以最多 280 株实例化树木补充层次，单株 140 三角面。树木避让城邑、水域、道路及陡坡；不随刷新随机重排。
- 地理数据或模型失败时明确提示，保留城邑铭牌与地图操作。样板不加载存档、不推进世界，不修改机制或数值。

## 验证与边界

- 4 项非 UI 定向测试通过：地图样式、植被确定性及城邑排除、GLB 单场景完整性与三角面／材质预算。`npm run build` 与 `git diff --check` 通过；保留既有大包体提示。
- 页面、两项模型、在线矢量入口及高程瓦片的本地 HTTP 请求均返回 200。
- 前端画面、模型落地、缩放手感、植被疏密和实际帧率待用户人工验收；没有执行浏览器自动化、截图验收、全量或长局测试。
- 美术目标图不等于本次浏览器实机效果，是否符合已确认风格须以本地样板验收为准。未部署、未推送。

## 浏览器复现与根因修复

- 用户再次反馈空白，并明确授权本轮使用浏览器测试和优化。实机复现为只有底色与城邑模型，5 个地图源均未完成、渲染要素数为 0；关闭模型仍然空白。
- 真正根因是独立入口遗漏正式地图的 `maplibre-gl-worker.mjs?worker&url` 配置，瓦片下载成功不代表 Worker 完成地理数据处理。样板现显式设置 Worker URL 与 2 个工作线程；此前状态提示修正并未解决此根因。
- 修复后浏览器中 5 个源全部完成、区域视图可查询 235 个渲染要素，地形与水系可见。完成长安／洛阳定位、俯视／立体切换的实机检查，无控制台警告或错误。城邑定位缩放从 10.7 调至 11.8，便于查看模型。
- 临时诊断面板和隔离参数已移除。5 项局部测试及生产构建通过，未执行全量／长局测试；这次验证加载与操作恢复，不代表美术目标完全验收。

## 正式入口改用样板的完整 Three.js 渲染链路（替代上一节接入方式）

- 用户指出正式地图与样板不同，确认应以样板渲染扩展全国。此前仅迁移资产和调色、继续使用 MapLibre 地形的交付不符合要求。本轮已将 `WorldMap` 的实际创建对象换为 `ThreeCampaignMap`，移除正式入口的 MapLibre 地图、Worker、样式表及独立城邑／军队渲染图层。保留的数据与事件适配只服务原游戏操作；地形、城邑、军队由一个 Three.js 场景和渲染器绘制，共享光照、雾及投影阴影。
- 使用样板 `terrainMaterial`、`waterMaterial` 和季节材质，扩展了全国地形着色范围。原始 DEM 保持米制，地图采用 Mercator 公里坐标、10 倍高程展示；城址平整、河流有限谷地贴合／开浅槽、城郊农田和确定性疏林沿用样板展示思路。城池采用同一组 Blender 模块，营建、国家旗帜、军队位置与命令仍读取正式世界状态；不使用样板演示局。
- 新增本地全国 DEM：48 张真实 AWS Terrarium z5 瓦片，2048 × 1536 样本／12 MiB，覆盖全部游戏城址。全国网格预算约 19.8 万顶点；拉近后按需加载同来源 z8 的 3 × 3 瓦片，细化网格约 14.8 万顶点，替换对应底图区块并衔接边缘。细化失败明确提示并保留真实离线底图，不生成替代山丘。现有 Natural Earth 陆地／河流保留本地使用及署名。
