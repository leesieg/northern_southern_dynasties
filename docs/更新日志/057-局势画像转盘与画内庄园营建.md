# 更新日志 057｜局势画像转盘与画内庄园营建

更新日期：2026-09-24

## 本轮变化

- 局势由刻度仪盘改为三阶段画像转盘：安定对应鹤与宫阙，动荡对应龙与风云，危局对应虎与战火。实际阶段变化时旋转切换，点击徽章可以预览其他阶段，预览明确标注并提供返回当前入口，不改变世界状态。
- 转盘使用一次性切换动画，不持续空转；遵循系统“减少动态效果”设置。下方保留实际国策、资源修正与局势推力，画像预览不替换实际结算数据。
- 局势与集团页压缩页签、指标、成员及动作间距，统一网格；集团领袖、成员与操作集中在一张紧凑卡片中。
- 庄园窗口缩小为最大 860px，并按可用屏幕高度收缩；增加旧金、深木色双层框，庄园名称放在顶部中央。
- 移除庄园常驻营建侧栏。点击画中建筑在画内展开营建详情，展示实际费用、工期、等级、效果及阻止原因后确认；家事作为画内独立浮层保留。

## 美术与验证

三阶段画像为本轮 AI 生成的原创南北朝题材素材，文件位于 `public/art/court/dynasty-phases.png`，共用横向图集，无参考游戏素材拷贝。保留既有庄园画面与建设状态联动。

50 个测试文件、439 项测试通过，生产构建通过；仍有既有大分包提示。未改变集团结算、营建费用或存档结构。未进行浏览器自动化验收；转盘画像裁切、动画、集团密度及庄园窗口比例待用户人工验收。未部署或推送。
