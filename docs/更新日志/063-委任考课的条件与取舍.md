# 委任考课的条件与取舍

日期：2026-09-24

- 委任类型卡展示常额钱粮，悬停／键盘聚焦可查收益、代价及当前阻止原因；不可用类型仍可选中查看和调整承办人、地点，实际委任受规则限制。
- 所选差事集中说明所得、代价、任职条件、名额与劳力占用。比较三种方案的钱粮、有效办理日及质量；预估复用实际办理效率，不包含赴任、等待审批或中途阻碍，也不承诺外交成功。
- 季议采用重心卡片与独立确认，议定后重点类每日工作量 +1、其他类 −1（总效率最低为 1）；未议定不施加倾斜。考绩保留重点基础 24、其他 20，按质量及贡献分配。显示受影响的在办差事，玩家与 NPC 共用规则，无新增存档字段。
- 审批、退回、追加、缓办、强令推进、延期及结案可查真实条件与后果；审批时展示拟案质量与工期，拟案时提示剩余限期及逾期风险。固定建筑等级等效果不随质量放大。

验证：459 项测试／51 个文件通过；生产构建通过（既有大包体提示保留）。新增规则测试覆盖季议资源倾斜、方案预算／工期／质量取舍、工作量一致性与存档恢复。界面与操作由用户人工验收，未做 UI 自动化。未部署或推送。
