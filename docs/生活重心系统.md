# 生活重心与公私修习

2026-10-10 根据《重构生活重心系统》对话验证并落地。保留管理、外交、军事、谋略四类经验；每类公私两重心、20 个技能（通用 2、公向 9、私向 9），全部配置与实际前置来自 `src/data/lifestyles.ts`。公私是职责及受益范围，不代表善恶；可以兼修，切换不删除已学技能。

| 分类 | 公向 | 私向 |
| --- | --- | --- |
| 管理 | 经世理政：亲治财政、县域收成、营建与承办公务 | 治产持家：本人庄园营建、安置、作坊、保管及宽租留户 |
| 外交 | 奉使交邦：实际使者交涉评分、交涉日数、外交公务 | 交游结亲：本人赠礼、交好、议婚接受度与减压 |
| 军事 | 统军经武：本人实际统率的公军战斗、围城及军粮军饷 | 修武蓄众：本人安全、亲统自有私军及私钱供养 |
| 谋略 | 谋国辅政：合法辅政游说、中枢／御史履职及职责内反制 | 谋身营势：本人隐秘关系、内应、拉拢、敌对计谋及自保 |

## 成长、队列与操作

每 360 累计经验获得 1 点本类技能点；技能点是“累计经验整除 360 减已学节点数”的派生值，没有另一份钱包。初选全人一生只赠一次 360 经验，至少一个公向和一个私向特色节点可以直接学习。切换重心冷却 90 日，不再赠点。

持续投入基础每月 18；性格契合、勤勉、实际在场指导合计最多 +2；完成匹配当前分类的真实实践每月最多 +2。高压力保留基础成长，暂停额外研习。基础与适配按实际投入日占该自然月日数的比例积累，在下月结算整数经验；首月、月底选重心、不同分类间切换不能各领取整月经验。全人全来源上限 22，实践额度由全分类共享。存读、重复推进同日、同月多次完成行动不能重复获奖；离线和跳过的世界日不补发。

实践接入已成功的庄户安置／庄粮赈济、工程完成、实际承办公务、实际使团获准、本人赠礼、成功计谋／交好。取消或未成功任务不授予实践经验，基础成长不消耗私人或公家资源。常规月度研习选择已取消，旧待研习在迁移时清理，不增发旧制 30／45 经验。

最高速首次入门点后剩余 19 点需 6840 经验：18/月约 31 年 8 月，20/月约 28 年 6 月，22/月需 311 次月结，约 25 年 11 月。保证的是完整一类内容容量，不是公私各学 25 年；旧档已有成长不追罚。

默认自动学习。顺序优先当前公私方向，再通用、再另一方向，实际缺失前置先行。玩家可指定本类优先技能或暂停自动学习，技能点保留；手动学习与自动学习执行同一校验。重要学习结果写人物纪事，不生成月月暂停弹窗。合资格 NPC 按实际能力、职责、资产与性格选择，遵守相同成长、前置、冷却与人口兵源规则，不花玩家资源、不代办玩家家事；退休历代玩家不自动代办。

## 实际作用范围

结算使用 `lifestyleEffects(world, context, actor)`，原始汇总 `lifestyleBonuses` 只供解释与内部聚合。职责及资产权限仍由原系统核对，重心不授予官职、通行、缔约权、土地或兵额。

- 地方公款加成取当前实际治理者，并在公私农业收益分配后修正公款部分；私产技能和私向能力不提高地方公库。县域收成仅生成一次，庄粮仍由同批真实收成分配。
- 庄园读取实际主人且须仍可经营；作坊只提高已有庄户与建筑的加工收入，保管只降低实际损耗、不减仓容溢出；安置钱费不改变县域人口、承载及同源兵员额度。易主后效果立即换人，预估与结算复用 `estateStorageLoss`。
- 新工程按公私实际范围报价，开工锁定工期与费用。在建工程不追改；工程师折扣只计算一次，存档接受新的整数百分比而继续复核金额、工期与前置。
- 军队战斗与后勤取实际统帅，不因玩家能操作该军而共享玩家技能。公向只作用公军；私军专长取亲自统率自己私军的所有者，通用技能取实际统帅。私军供养减费只在所有者用本人私钱支付时生效，同一所有者兼统帅不重复计入；不增加动员比例或凭空兵员。
- 外交取实际使者的公向专长，交涉预览和抵达结算共用评分；交涉日数折扣不减少行程，选人指标包含专长。君主私人关系技能不会直接成为使者加成。
- 计谋槽位保持 personal/hostile，不把敌对槽位冒充公向。公向政治招揽只认可当前实际执政者维护在位君主与现任执政安排；中枢／御史履职每 5 点辅政专长加 1 评分。其他私人计谋用私向。反制取目标能力及同地有效中枢／御史保护者的最高反制，不重复叠保护者；私人护卫仅抵御本人绑架／谋害，所有行动仍用原私财钱包和权限。
- 个人交往和议婚读取当事人自己的私向及通用专长；能力来源说明仍可查。扩树后通用人物技能能力加值保留原 5 点上限，公私场景分别核对适用学习与当前方向，避免 20 节点使能力膨胀或私产技能串入公款。

## 状态与旧档

`World.lifestyles.version = 4`；记录持有者为实际人物 ID，虚构玩家为 fictional。

| 字段 | 定义、单位与边界 | 用途 |
| --- | --- | --- |
| xp | 人物按四类持有的经验存量，点，每类 0–7200 | 推导余点、距下点进度；已学不扣 xp，只计技能点消费 |
| perks | 按学习顺序保存的技能 ID 元数据，总计最多 80 | 实际前置及效果来源，不继承给后继人物 |
| month.credit | 自然月未结算成长进度，点，四类合计不超过 20 | 按真实投入比例积累，下月一次并入 xp，不与 xp 重复计入 |
| month.practice | 本月真实实践进度，点，四类合计最多 2 | 全来源共同封顶，下月一次结算 |
| auto / priority | 自动学习开关及按分类的优先技能 ID 元数据 | 改变顺序，不增发资源，先学实际前置 |
| origin / legacyXP | 新制开始世界日与旧制合法经验基线元数据 | 校验新制月度经验，旧进度不按慢速倒查 |
| reselect | 旧档一次重选方向资格状态 | 绕过一次旧冷却，不再赠初选点 |
| LifestyleBonus | 人物技能配置汇总的派生值，百分比或评分点 | 各真实场景筛选，不持久化、不作为另一份资源 |

合法版本 1 按原 120 单位校验并乘三；版本 2、3 保留经验、技能 ID、合法前置、余点与新工程快照，再显式映射旧重心。迁移不补发过去月份、技能点、私财、人口或兵额。技能强度按新版配置生效，不追扣既得资源。继任者使用自己的 NPC 记录或新建空记录，前任记录保留。损坏记录拒绝加载，不静默清空。

UI 仍只发 lifestyle 命令，Worker 在副本复核与持久化成功后替换世界，保存失败不扣点或改变安排。月预算、优先技能分类、日期、前置顺序、全局入门点与旧经验基线均校验。
