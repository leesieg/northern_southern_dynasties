# 生活重心系统

2026-09-22，已接入游戏规则、Worker、存档及左侧抽屉。首版为军事、管理、交游三条生活路线，每条三个可选重心、一棵五节点技能树，共九种重心、十五个技能。数值按本作游戏日节奏设计，不是历史事实，也不是 CK3 数值复刻。

## 参考与取舍

参考 Paradox 的 [CK3 生活重心介绍](https://www.paradoxinteractive.com/games/crusader-kings-iii/legends-of-crusader-kings-iii/emir-yahya) 和 [交游重心介绍](https://www.paradoxinteractive.com/games/crusader-kings-iii/legends-of-crusader-kings-iii/petty-king-murchad)：人物选择一个重心取得当前加成，通过经验与技能树形成个人专长，更换重心保留已学能力。结合本作现有战争、营建与社交实施三条路线，不展示尚未接入规则的技能。

本版没有完整 CK3 路线数量与事件库；暂不做谋略／学识独立路线、教育阶段、洗点、NPC 自动学习或技能遗传。未复制 CK3 美术资源，界面复用项目原创彩绘图标。

## 玩家循环

1. 在左侧“重心”或“人物 → 生活重心与技能树”进入抽屉，选择路线和重心。
2. 每个人第一次选择时获得该路线 120 入门经验，即 1 个技能点；这是教学节奏设计。后续切换不重复领取。
3. 每个实际推进的游戏日积累当前路线经验：基础 3，性格契合 +1，勤勉额外 +1；压力达到 80 时 -1。暂停、刷新页面和离线不产生经验。
4. 每 120 经验产生一个对应路线技能点，点击满足前置的节点学习。经验累计值不扣除，可用点数为“累计经验整除 120 − 已学本路线节点数”。每路线最多 600 经验、五个节点，不跨路线挪用点数。
5. 每 30 日出现一次当前路线研习选择：深研获得 30 经验，勤勉者为 45；有压力系统时压力 +8。休整则不获得经验，压力 -8。经验到上限按实际剩余额度结算。
6. 研习不强制暂停世界；左侧重心按钮显示待办标记。未处理时只保留一件，不堆积无限事件。事件保留触发时的路线，换重心后也不会改发奖励。处理后不能重复结算。
7. 更换任意重心需距上次选择满 90 日；只更换当前加成，保留所有已学技能与各路线经验。技能不会返还或洗点。
8. 学完五个节点获得后天专长：兵略家／经世者／纵横家，在人物、社交和重心页展示。它与先天遗传特质、基础性格分别存储。

军事与管理每人均可学习，但军务和公款／公粮效果依赖历史沙盒；军务效果还需当前人物的军务授权。虚构教学人物尚未开放交往和压力系统，面板会明确提示，适合先学营建相关管理技能。

## 重心与技能效果

| 路线 | 三种当前重心 | 技能树与实际结算 |
| --- | --- | --- |
| 军事 | 兵法：伤害 +5%；军需：军粮 -5%；军纪：军饷 -5% | 整训部伍：伤害 +10%；粮道筹算：军粮 -15%；攻城法度：围城日数 -15%；久练成军：军饷 -15%；兵略家：伤害 +10%、围城日数 -10% |
| 管理 | 营造：造价 -5%；理政：亲治城市公款 +5%；农桑：亲治城市公粮 +5% | 审度物料：造价 -5%；统筹工役：工期 -10%；明核账籍：公款 +10%；劝课农桑：公粮 +10%；经世者：造价 -5%、公款 +5% |
| 交游 | 礼仪：接受度 +5；宾客：赠礼费用 -10%；敦亲：每 30 日额外减压 3 | 通晓礼数：接受度 +8；投其所好：赠礼费用 -20%；善结人缘：赠礼额外 +5 好感；循循相交：新交好成功率 +10 个百分点；纵横家：接受度 +7、每 30 日额外减压 3 |

每棵树：起点 → 左右两分支；左支再深入一级；终点要求左支深入节点与右支节点都已学会。界面展示连线、明确的前置名称、可用点数与不可学习原因。配置唯一来源为 `src/data/lifestyles.ts`。

同类百分比按基础值叠加，再做原有取整；并非逐次复利。例如营造、审度物料和经世者共减基础造价 15%。建设继续叠加节俭、家族治产等原修正，新工程记录开工时造价与工期，在建工程不追改。

军事加成只作用于玩家所在政权、且当前人物有军务授权时的军队。实际每日耗粮、每 30 日军饷、野战伤害与围城门槛均接入；军务面板、动员文案和财政预测同步使用结算函数。失去授权后停止应用，不赋予敌军同样收益，不越过原有战争和动员权限。

税粮加成仅作用于当前人物实际治理且本国控制的城市，不能从人物技能推断为全境加成。交游改变真实接受度、赠礼扣费与好感；成功率仍限制在 5%—95%。交好开始时锁定成功率，学习技能不会修改正在进行的行动。减压在原有 30 日结算中生效，压力始终在 0—100。

## 人物、遗传与存档

`World.lifestyles` 版本 1 按人物 ID 保存当前重心、切换日期、各路线累计经验、按解锁顺序保存的技能 ID、研习日期与待办。虚构玩家用固定 ID `fictional`。只为实际游玩的角色建档，未接管人物不自动获得离线经验。

家业交接保留前任记录，为新人物建立独立未选择重心的记录；经验、技能、后天专长均不遗传，不进入 Genome。未来子代的教育可以改变学习效率，但必须通过新的成长规则接入，不能直接复制父母专长。

旧档缺少整个字段时，读取后补齐零经验记录，不按已过天数补发经验；旧工程报价保持不变。新字段存在但损坏时拒绝加载，不静默重置。校验版本、人物资格、当前人物记录、经验范围、点数预算、重复技能、前置顺序、重心 ID、日期和研习状态。

UI 只发 `lifestyle` 指令。Worker 先在副本验证并执行，再写入存档，成功后替换世界；失败仍保留原经验、技能和重心。避免重试重复消费或只改内存未保存。

## 验证与人工验收

规则测试覆盖首选技能点、每日成长与特质、冷却、跨路线保留、研习防重复、全树解锁、工程快照、税粮范围、赠礼扣费、实际军粮／伤害／围城、继任者独立、旧档迁移与损坏拒绝。Worker 测试覆盖学习后保存／继续及写入失败不扣点。全量 `npm test` 和 `npm run build` 为交付检查。

人工验收入口：刷新游戏 → 左侧“重心” → 选择“管理／营造” → 学习起点 → 城市或庄园查看新报价；推进时间观察经验、技能点和月度研习。历史沙盒可验证军事与城市税粮路线；人物交往页可核对接受度及赠礼报价。再保存返回菜单、继续游戏，确认重心与已学技能保留。界面与树连线效果待用户人工验收，未运行浏览器自动化。
