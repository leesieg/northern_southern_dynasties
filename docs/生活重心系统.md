# 生活重心系统

2026-09-22，已接入游戏规则、Worker、存档及左侧抽屉。首版为军事、管理、交游三条生活路线，每条三个可选重心、一棵五节点技能树，共九种重心、十五个技能。数值按本作游戏日节奏设计，不是历史事实，也不是 CK3 数值复刻。

## 参考与取舍

参考 Paradox 的 [CK3 生活重心介绍](https://www.paradoxinteractive.com/games/crusader-kings-iii/legends-of-crusader-kings-iii/emir-yahya) 和 [交游重心介绍](https://www.paradoxinteractive.com/games/crusader-kings-iii/legends-of-crusader-kings-iii/petty-king-murchad)：人物选择一个重心取得当前加成，通过经验与技能树形成个人专长，更换重心保留已学能力。结合本作现有战争、营建与社交实施三条路线，不展示尚未接入规则的技能。

本版没有完整 CK3 路线数量与事件库；暂不做谋略／学识独立路线、完整教育阶段、洗点或技能遗传。NPC 自动学习于 2026-10-03 接入。未复制 CK3 美术资源，界面复用项目原创彩绘图标。

## 玩家循环

1. 从“人物 → 重心 → 生活重心”或顶部“选择重心／技能点”待办旗帜进入同一弹窗。切换路线后直接单选重心，效果在卡片与固定底栏预览，点击“确认重心”才生效；不再另开“调整重心”弹窗。技能点旗帜优先打开当前有余点的路线，否则打开仍有余点的旧路线。
2. 每个人第一次选择时获得该路线 360 入门经验，即 1 个技能点；这是教学节奏设计。后续切换不重复领取。
3. 每个实际推进的游戏日积累当前路线经验：基础 3，性格契合 +1，勤勉额外 +1；压力达到 80 时 -1。暂停、刷新页面和离线不产生经验。
4. 每 360 经验产生一个对应路线技能点，点击满足前置的节点学习。经验累计值不扣除，可用点数为“累计经验整除 360 − 已学本路线节点数”。每路线最多 1800 经验、五个节点，不跨路线挪用点数。2026-10-03 将每点成本由 120 提高至 360，日常与月度经验来源不变，入门点之后的积攒成本为原来的三倍。
5. 每月 1 日出现一次当前路线研习选择：深研获得 30 经验，勤勉者为 45；有压力系统时压力 +8。休整则不获得经验，压力 -8。经验到上限按实际剩余额度结算。
6. 研习不强制暂停世界；人物重心入口显示待办提示。未处理时只保留一件，不堆积无限事件。事件保留触发时的路线，换重心后也不会改发奖励。处理后不能重复结算。顶部另显示未选重心及可用技能点待办，全部取自当前人物成长记录；选定重心或用完所有路线余点后相应旗帜移除，不创建存档任务或假进度。
7. 更换任意重心需距上次选择满 90 日；只更换当前加成，保留所有已学技能与各路线经验。技能不会返还或洗点。
8. 学完五个节点获得后天专长：兵略家／经世者／纵横家，在人物、社交和重心页展示。它与先天遗传特质、基础性格分别存储。

军事与管理每人均可学习，但军务和公款／公粮效果依赖历史沙盒；军务效果还需当前人物的军务授权。虚构教学人物尚未开放交往和压力系统，面板会明确提示，适合先学营建相关管理技能。

## 重心与技能效果

| 路线 | 三种当前重心 | 技能树与实际结算 |
| --- | --- | --- |
| 军事 | 兵法：伤害 +5%；军需：军粮 -5%；军纪：军饷 -5% | 整训部伍：伤害 +10%；粮道筹算：军粮 -15%；攻城法度：围城日数 -15%；久练成军：军饷 -15%；兵略家：伤害 +10%、围城日数 -10% |
| 管理 | 营造：造价 -5%；理政：亲治城市公款 +5%；农桑：亲治城市公粮 +5% | 审度物料：造价 -5%；统筹工役：工期 -10%；明核账籍：公款 +10%；劝课农桑：公粮 +10%；经世者：造价 -5%、公款 +5% |
| 交游 | 礼仪：接受度 +5；宾客：赠礼费用 -10%；敦亲：每月 1 日额外减压 3 | 通晓礼数：接受度 +8；投其所好：赠礼费用 -20%；善结人缘：赠礼额外 +5 好感；循循相交：新交好成功率 +10 个百分点；纵横家：接受度 +7、每月 1 日额外减压 3 |

每棵树：起点 → 左右两分支；左支再深入一级；终点要求左支深入节点与右支节点都已学会。界面展示连线、明确的前置名称、可用点数与不可学习原因。配置唯一来源为 `src/data/lifestyles.ts`。

同类百分比按基础值叠加，再做原有取整；并非逐次复利。例如营造、审度物料和经世者共减基础造价 15%。建设继续叠加节俭、家族治产等原修正，新工程记录开工时造价与工期，在建工程不追改。

玩家军事加成沿用本国军务授权限制；其余军队读取实际未被拘押统帅自己的重心与技能，不镜像玩家收益。实际每日耗粮、每月 1 日军饷、野战伤害与围城门槛均接入；军务面板、动员文案和财政预测同步使用结算函数。失去授权后停止应用，不越过原有战争和动员权限。

税粮加成读取实际治理者的个人技能，玩家与 NPC 共用，不从人物技能推断为全境加成。交游改变真实接受度、赠礼扣费与好感，议婚也读取双方各自的接受度加成；成功率仍限制在 5%—95%。交好开始时锁定成功率，学习技能不会修改正在进行的行动。玩家减压在每月 1 日结算中生效，压力始终在 0—100；当前没有完整 NPC 压力状态，NPC 学习和家事不修改玩家压力。

## NPC 自主生活（2026-10-03）

沙盒进行中，在世、年满 16 岁且未被拘押的 NPC 自主选择重心、积累经验、处理月度研习并按技能前置学习；历代玩家已退居人物不自动代办。优先级取自实际能力、性格以及治理者／统帅身份，不硬编码开局名单。当前树学完后才转向未完成路线，并遵守同一 90 日冷却。人物能力明细、实际治理城市、双方议婚及各军实际统帅消费这些成长。

月度家事生成和处理扩展至实际 NPC 家庭。儿童成长按父母监护办理，成年志向、姻亲请托和丧偶家事按性格、私财及现有办理条件选择。普通 NPC 父母年满 18 岁且有至少 180 私钱时，每 90 日检查 6–17 岁未受教直系子女，并从合法非玩家教师中延聘；初次与续期学资均实付教师，不因身份发放免费教育。

疾病、伤情及低健康按月检查；延医使用出资人的 30 私钱并维持 90 日照料，节俭或无钱者在实际出行／公务限制允许时休养。玩家本人及玩家子女的教育和养护保留玩家决定；NPC 不花玩家的钱、不消耗玩家技能点，也不替玩家处理家事。先前接入的 NPC 婚配、配偶团聚与添丁继续按真实居所、婚资、双方意愿和健康年龄限制运行。条件不足时无法强行办理，合适时再尝试；家事也可依法选择婉拒或尊重自主安排。

## 人物、遗传与存档

`World.lifestyles` 版本 2 按实际人物 ID 保存当前重心、切换日期、各路线累计经验、按解锁顺序保存的技能 ID、研习日期与待办，并用 `lastAdvanced` 世界日防止同日重复积累。虚构玩家用固定 ID `fictional`。合资格 NPC 从首次实际推进起建档，不按开局前、暂停或离线时间补发经验。

家业交接保留前任记录；新人物已有自己的 NPC 成长记录时继续使用，否则建立独立未选择重心的记录。经验、技能、后天专长均不遗传，不进入 Genome，不能直接复制父母专长。

旧档缺少整个字段时，读取后补齐零经验记录，不按已过天数补发经验；旧工程报价保持不变。合法版本 1 先按原 120 单位校验，再将经验乘三并转为版本 2，保留已学技能、可用点数及距下一点的进度比例；迁移只执行一次，不发放现金。新字段存在但损坏时拒绝加载，不静默重置。校验版本、真实人物资格、当前人物记录、经验范围、点数预算、重复技能、前置顺序、重心 ID、日期和研习状态。

UI 只发 `lifestyle` 指令。Worker 先在副本验证并执行，再写入存档，成功后替换世界；失败仍保留原经验、技能和重心。避免重试重复消费或只改内存未保存。

## 验证与人工验收

规则测试覆盖首选技能点、每日成长与特质、冷却、跨路线保留、研习防重复、全树解锁、工程快照、税粮范围、赠礼扣费、实际军粮／伤害／围城、继任者独立、旧档迁移与损坏拒绝。Worker 测试覆盖学习后保存／继续及写入失败不扣点。每轮按 AGENTS.md 选择局部验证并执行 `npm run build`；本轮待办与入口改动的实际覆盖见 `docs/迭代整合进度.md`。

人工验收入口：刷新本地游戏 → 顶部“选择重心”旗帜 → 选择“管理／营造”并确认 → 顶部提示可用技能点 → 在同一弹窗学习起点；也可从“人物 → 重心”打开。核对切换路线的预览、90 日冷却与固定确认栏，再保存返回菜单、继续游戏，确认重心与已学技能保留且旗帜准确更新。界面待用户人工验收，未运行浏览器自动化。
