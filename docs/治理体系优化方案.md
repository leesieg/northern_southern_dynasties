# 治理体系优化方案

状态：机制、交互与存档迁移已实施，457 项规则/接口测试及生产构建通过；UI 待人工验收。范围：人物任官、人口与地方经济、人口迁移与掠夺、集团政治、差事决策；保持既有地图与美术体系。所有参数为游戏平衡，不伪称历史人口统计。

## 完整目标

地方人口与地理产生生产和需求 → 朝廷确定优先级 → 按当前归属任命与授权 → 在有限钱粮、劳力、时间中分配 → 执行中选择代价 → 结果改变地方、人物功绩和政治格局。NPC 和玩家遵循相同结算。

## 人物与任官

统一登记与任职资格，开局可选与能否任官分开；纳入陈霸先等沿革人物，并支持已有关系人物与已登记后代。资格检查在世、成年、当前效忠、拘禁、繁忙和冲突职位；原始剧本国籍不能覆盖当前效忠。君主拥有法定授官权，但受权臣控制者须取得实际执政支持。常规荐任保留功绩门槛，实际执政者可破格授官并承担支持度与秩序代价。任命包含文书、交接、赴任、履职；候选人死亡、改换效忠、城市失守或道路受阻必须处理，不能凭空瞬移。一个人物不同时管理相距遥远的城市。

## 人口与地方经济

人口是民食、生产、兵源、税基的共同基础。人口增加，在同等条件下增加产出；土地承载不足时边际产出递减，不能无限增长。劳力受征募、工程、迁徙和承办人健康状态与地方动乱影响。地理条件、耕地、水利、商业与交通决定效率和城市功能；数据采用现有有来源地形，具体产能系数标为设计参数。

按月核算生产、民食、损耗、公共粮储、地方税收、行政支出、上缴与拨回。城仓提高容量和保管效率，不直接制造粮食。粮食有地点；中央原有储备不重复发给城市。税率影响财政与秩序，粮食不足影响人口与生产。农业、水利、市场等差事改变相应设施或效率，不凭空增加人口。刺史及 NPC 采用相同能力和生活重心修正。

迁徙由国家政策发起，明确来源、目的地、人数与方式：安置补助成本高、损耗低；强制迁徙成本较低、损耗和秩序代价高。扣除来源人口，按真实道路逐日行进，抵达增加扣除损耗后的目标人口。人口守恒：来源减少 = 抵达 + 在途 + 途中损耗；不得重复结算。道路中断暂停，失去控制可返还或取消，取消不退款已消耗成本。

军事掠夺须交战、军队驻留并占领敌方城市，受兵力和可掠人口限制；人口经安全路线押送己方城市，有损耗、地方秩序、合法性和外交后果。掠夺不改变法理归属，不能对友好/停战城市刷人口。征募真正扣人口，遣散返还存活兵员，战死不返还。

## 利益集团

君主不作为普通成员加入集团，改为眷顾、协商、裁决与平衡支持；登基退出普通成员身份。集团是政治主张组织，家族/职位/军队/地方为其利益基础。实力逐项展示：任官职掌、控制军队、管理地区人口与财政、家族声望、功绩和临时动员；同一资源不得重复计算。

每项国家行动按所属领域获得支持或阻力，影响实际成本、办理速度、地方秩序和朝野支持。集团强势并非对全部行动的否决权；任官、扩军、税收、迁徙、工程分别计算诉求。君主仍可推进但须承担后果。局势展示政治结果，集团解释来源，不新增无实际落点的装饰分数。

## 差事

以实际地方需求排序：必须处理、值得争取、自主经营。展示推荐原因、忽略后果、时间和资源占用；君主负责安排优先级和授权，官员承办，幕僚协助。不同地方与国家状态必须产生不同推荐。

差事方案与中途决策围绕具体矛盾：赈济的粮源与储备，农桑/工程的劳力与农时，征募的兵员与生产，清税的收入与地方关系，外交的让步与信任。加钱只解决经费问题，不能买通封锁、凭空产粮或消除一切政治阻力。方案分别改变时效、成果和民生，不存在无条件最优选项。

结算包含完成比例、实际支出、时效、民生与后续负担；支持取消止损、由执政者批准延期与改派。未使用资金退回原公共预算路径，不重复扣款或奖励；关键决策才暂停，普通推进使用既有授权。

## 界面与验证

城市政务聚合人口、经济分解、迁徙与军事掠夺；沿用图标卡片与确认、禁用原因，不新增全屏工具。局势显示集团实力来源与行动影响；差事列表突出需求理由，详情展示决策后果与结算。

验证：萧衍任命陈霸先并赴广州；同等级城市差异、人口/设施/税制修正、地方粮食与运输、迁徙/掠夺守恒、兵役守恒、集团身份与实力/政治效果、不同约束下差事取舍、取消退款与重复命令、NPC一致性、旧存档幂等迁移及坏档拒绝。执行 npm test 与 npm run build。视觉与交互由用户在 127.0.0.1 人工验收，禁止 UI 自动化。按主题本地提交，不推送或部署。

### 已落地的规则与参数

- 人口取代户数作为城市权威字段，旧档按每户 5 人迁移一次；不赠送地方粮食或公款。新档人口按城市级别及地形初始化，非历史户籍还原。生产采用有效人口：土地承载以内全额计算，超出部分按 25% 边际效率；水利增加承载与产出，刺史管理能力和生活重心共同修正，正在执行的地方工程占用劳力。月度民食按人口计算；饥荒、动乱减少人口，秩序稳定时人口按比例增长。
- 地形农业效率为 0.75—1.35，商贸节点与普通城市税基不同。公款继续复用地方—上级—中央账本；各城单独保存公粮，仓容随人口及城仓变化，每级城仓增加 200 容量并降低保管损耗。都城剩余公粮进入中央仓，地方粮食通过运输抵达其他城市。调出都城时可动用中央库存。
- 迁徙有招徕安置、强制迁徙、战时掠夺三种方式，按人数、道路长度和治理能力报价，明确损耗；单城保留至少 100 人，承接上限 100 万是模拟保护界限。掠夺最多为驻军人数和当地人口两成中的较小值，须交战并实控敌城；有押送队伍时不能重复掠夺。掠夺降低当地秩序、合法性、支持度、国家信用及两国关系。途中道路失控暂停；可沿安全路径撤回，撤回增加损耗且不退组织费用。队伍有顶部事项旗，完成有抵达通知。
- 动员、征募及补员均扣除对应人口，遣散返还存活兵员。军队每日消耗按兵力和生活重心计算，军粮队从真实粮仓扣粮、沿路送达并计损耗；随军粮上限调整为 600，防止旧上限让长途围城无法维持。双方军队采用同一补给规则。
- 刺史候选人使用已登记关系人物和当前效忠，陈霸先可受任。成年、存活、拘禁、在途任命及现有公务冲突都有检查；文书抵达后等待本人到场，赴任后撤销原城市/中央职务。权臣控制下的君主需执政者接受度达到 60，或恢复亲政。低功绩破格任命有支持度与地方秩序代价。效忠改变会撤销不兼容公职并结算原有差事。
- 君主不参加普通结党；集团势力来源在悬停中逐项展示，成员依据官职、地方人口税基、统领军队、家族声望和功绩贡献。任官、改革、征税、军务、迁民、赈济和商贸有不同立场；执行改变实际支持/紧张，相关差事效率最多增减 2。集团页显示各领域立场，国家行动提示显示支持与反对来源。
- 差事推荐以本地民食、秩序、驻军状态、财政及区域功能排序。默认首先看到推荐及原因，保留自主选择。按部就班、从容详办、增拨赶办的基础质量分别为 100%、115%、85%；协商缓办提升质量并增加工期，强令推进损害秩序/质量并增加压力，雇工赶办消耗额外预算并承担地方代价。道路阻断或严重失序时不能用追加经费消除阻碍。大工程按规模确定初始限期，执政者可批准一次 30 日延期，承担支持和考绩代价。
- 专款保留实际累计耗用，延期或新增工作量不会把已支出金额倒退；撤回返还未用公款和粮食，已完成的部分民政收益可以保留。结案展示完成比例、花费、退款、时效、成果质量、实际地方影响与参与者考绩，重复结案不会重复奖励。

### 数据与验收边界

人口、农业效率、承载、运输损耗及政治系数均为游戏参数；没有引入未经核验的历史人口数字。复用现有人物登记、道路、城市控制和财政实体，不新增虚构历史人物或史实。后代任官指已登场且登记的人物，本轮不额外扩展独立的婚育/出生系统。月度粮食模型仍为策略模拟口径，不做逐户农业生产仿真。

人工验收入口：城市 → 刺史席位 / 政务 → 人口及迁民转运；局势 → 利益集团；政务 → 差事簿。建议以萧衍新局先任命陈霸先为广州刺史，再对比不同地区人口产出、组织迁徙/调粮，观察顶部事项和赴任结果。掠夺需要真实宣战、驻军、占领与安全押送路线，不能在和平状态直接试用。
