# 军事系统整合

本轮依据用户引用的《设计军事系统方案》实施。保留现有右上军队栏、地方征募、战役委任、公库与道路运量，军事入口复用权威规则。数值为游戏参数，并非史实或 EU4 参数复刻。

## 验证与实施清单

- [x] 军权：命令与机密数值共用实际授权；不以旧 `mandate` 放开全国军权。君主可逐军授权自主行军，手动军令恢复亲自控制；普通人物的非授权部队继续由 AI 行动。
- [x] 军事入口：军情、军队、战争、将领、粮运、战史；批量征募整单复核，真实训练后集结；联合军令支持集结、分路与按粮仓分散驻防。
- [x] 战争：对称固定价值分数、参战方续战意愿、双方割地与赔款组合、同阵营割地受益国、盟国单独退出；其他战场的占领、敌对与部队任务保留。
- [x] 战史与败退：稳定战斗 ID、统帅及阵营加入快照、结束时一次计分、真实撤退；军队消失不抹去档案或欠饷。沿用 5,000 场档案上限。
- [x] 补给：提前期加安全库存、可靠在途扣除、真实会合据点、补给优先级、民食储备政策、民夫与生产/征募互斥、缺粮分级；AI 与旧动员也不能借用已征民夫或远方粮仓。
- [x] 围城：同城唯一阶段实体，实际供粮兵力决定包围；阶段种子可恢复，守城官员、城粮、城防和接近援军影响判定。封锁影响入城产出，撤围后重新计算；玩家主官自行裁定议降。
- [x] 人物：有效驻留日研习、公军自荐共用现行用人评价、私财部曲、逐军实际随行；忠诚、制度信任和凝聚力有规则消费者，拒命保留部队，起兵与个人投降逐兵团分裂。
- [x] 归附：危机、饥荒、官员态度、驻军与接纳国军力共同限制提议；七日处置期后接纳、开战和实控转移同次结算；法理、违约责任和旧职权分别处理。
- [x] 表现：一个 MapLibre/Three.js 共享图层，原创步兵、骑兵、攻城器械代表模型；状态来自规则层，远景军旗、低画质、减少动态和加载失败回退。
- [x] 存档校验、局部测试、构建、数值审计及第 069 轮更新记录。

## 验收边界

141 项受影响范围局部测试通过，生产构建通过。包括 116 项军事/战争/生涯/编制/逐军统帅测试、21 项关系/暂停事件测试，1 项 Worker 归附保存回滚与读档暂停测试，以及 3 项旧动员/行军定向测试。一次暂停测试超过 Vitest 默认五秒，单独以 30 秒预算重跑通过；另修正了两份旧测试用三十日冒充日历月的夹具。没有减少断言。

不运行长局或完整游戏回归。界面与 3D 表现由用户人工验收；不使用浏览器自动化或截图。模型帧率、外观、窄屏布局尚未经人工确认。保留既有大分包提示。未发布或推送，本地入口为 http://127.0.0.1:5173/。

## 方案中的取舍

- 右上军队栏保留全部有权指挥的现役单位，遵守项目约定；左侧军事入口复用它的详情、任将和军令。
- 使用联合军令组织多军，保留独立统帅、账户、兵团和忠诚；没有为一次部署再造永久军团或巨型合军实体。
- 复用单一军事能力及现有生活重心、功绩与任用规则。研习和战斗历练进入能力来源，不新增四套暂时没有独立决策的专长数值。
- 守军来自现役部队，不生成额外城防兵员；民食仍按月结算，不增加第二份日耗。围城工程不是完成概率，阶段概率明确指向下一轮迫降。
- 使用原创简化兵模，避免未经许可的 glTF 素材及新的资产下载依赖。没有把动画当作规则时钟，也未宣称完成专业骨骼动画或视觉验收。
- 不新增没有对应设施/官职规则的护粮官、兽力池或独立前线仓库。运输使用既有城市、民夫、真实预算、道路运量和在途实体；危险粮道可转移军队、调粮或撤军。
- 议和覆盖现有割地、赔款/分期、宗属、吞并和新增归附确认；解除独立外交关系继续由已有外交入口完成，不在战争窗口绕过其合法性规则。
