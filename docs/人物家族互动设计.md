# 特质、家族与人物互动：规则与落地方案

本轮为已授权实施的系统设计，沿用 546 年、11 位主要历史人物、单人浏览器和 Worker 权威世界。参考 CK3 的特质约束、关系反馈、长期行动与家族持续资产，不复制其代码、图片或数值。历史身份与亲属链接沿用逐人来源；以下特质、属性、好感、压力、世业、互动结果全部是玩法参数，不作为历史人格判断。

## 玩家循环与交互

人物面板进入“人物与家族”，分为自身、家族、交往。先看特质和效果，再选择目标人物，查看关系来源、接受度构成、费用、冷却与预计结果，然后执行。长期交好使用游戏日推进并在完成时结算，暂停不推进；读档保留已锁定进度与随机状态。人物交往不是聊天生成器，所有效果由确定的游戏规则写入。

核心闭环：选择人物 → 了解特质 → 营建与压力取舍 → 向他人交好、赠礼或施压 → 请援／延请协理 → 积累家族名望 → 解锁世业 → 指定亲属交接家业 → 保留工程与目标继续本局。界面提供禁用原因、费用及后果，重大交接需在游戏内确认。

## 特质与属性

首版六项设计特质：勤勉（工期缩短、动工增压）、节俭（造价降低、赠礼增压）、慷慨（赠礼额外好感、请援增压）、善交（接受度提高）、多疑（交好耗时增加）、坚毅（每月减压）。君主、执政、宗室、将领按身份模板分配两项，不暗示史书已有对应 CK3 特质。

外交、理财、军事、谋略四属性由角色模板与特质导出。本轮外交用于接受度；理财／军事／谋略作为人物概况展示，未参与战斗或计谋时明确标为预留，不能显示不存在的效果。压力 0—100，80 以上延长新工程；休整花费资源减压。已开工的价格与工期锁定快照，不随读档、协理变更或家业交接回算。

## 家族与世业

家支按“政权 + 氏族”区分，避免把东魏与西魏的元氏自动视为同一家支。成员来自已录关系与人物名录，不从同姓推断亲属。家族名望初始 40，每月与竣工增长；三条世业各两级：治产降低新营建成本，敦亲增强正向交往，家学增加每月减压。每级花费 30、60 名望，跨继任者保留。

可指定已录、同家支的直系后代或兄弟为家业继任者，排除本人、已交接退居者及父辈。此操作为“家业交接”，不等于皇位／官职的历史继承。确认后角色身份切换，钱粮、原家宅、辖城营建职责、所有建筑、在建工程、名望、世业及原局目标保留；自身压力重置为 20，协理与长期交好撤销，旧角色进入交接记录。同一次身份不能反复往返刷新资源。无已录候选者时显示资料覆盖限制，不凭空生成子嗣。

生育、死亡、皇位与官职继承、支系分裂、继承战争不在这一套单城家业规则中冒充已实现；这些系统需要性别、年龄、婚姻、合法性、继承法与完整家谱数据，再扩展独立规则。

## 人物交往

好感是 NPC 对当前玩家的态度，范围 -100—100；家属、同政权与异政权有不同起点。家支名望与人物好感不混为同一资源。

| 行动 | 成本／周期 | 结果与限制 |
|---|---|---|
| 赠礼 | 30 钱，10 日冷却 | 基础 +15 好感，受慷慨与敦亲加成；节俭者增压 |
| 长期交好 | 20 钱，14 日；多疑者 18 日 | 同时一项；接受度转为 5%—95% 成功率，开工锁定，结算推进已保存随机种子 |
| 请援 | 接受度至少 60，30 日冷却 | 取得 70 钱，好感 -20；本次请求发生前明确展示结果 |
| 延请协理 | 40 钱，接受度至少 60 | 同政权、同一时间一人；新工程缩短 10%，不重算已有工程 |
| 施压 | 10 名望，15 日冷却 | 好感 -25、压力 +15，取得一次人情；无名望不能执行 |
| 兑现人情 | 持有该人一份人情 | 消耗一份，取得 50 钱，好感 -10；不是无限免费资金 |
| 休整 | 20 钱，15 日冷却 | 压力 -30，可在压力较低时执行但不会负数 |

接受度显示：基础值、当前好感、外交、同政权／异政权、善交加成、目标多疑修正。不是伪随机“同意动画”；确定性请求按阈值执行，长期交好按可复现随机数结算。未达门槛请求不扣费。全部行动可被 Worker 拒绝，UI 禁用不是唯一校验。

## 状态与兼容

新增 world.social 的版本化状态：起始人物、设计特质、按人物区分的关系／人情／冷却、压力、家族名望、世业、继任者、交接记录、协理、长期交好及随机种子。当前角色 ID 仍与世界人物栏关联；本局目标始终从起始人物导出，杜绝交接换目标套利。

新历史开局直接创建状态；旧历史存档通过校验后补齐中性初始状态。旧工程维持原价工期；新增工程记录修正快照。原沈行舟入门局继续可玩，此批社交系统面向已有历史人物，不伪造沈氏谱系。存档校验覆盖版本、人物／家支、候选人、金额、好感范围、冷却、种子、工程快照、交好时间及交接链；非法数据拒绝导入。命令先完整报价校验，再原子应用，失败不得部分扣款。

## 验证与验收

代码验证必须覆盖：特质成本与工期、压力惩罚、长期行动暂停／到期／读档一致、请求拒绝不扣费、冷却防重复、协理与世业效果、跨家支继承拒绝、交接资产不复制、原局目标不变、旧档迁移及篡改拒绝。每个历史开局仍可在 120 日内完成。

浏览器人工验收：新开任意历史人物 → 人物与家族 → 查看特质 → 赠礼／交好 → 关闭窗口推进时间 → 请援／协理 → 建设查看实付与实际工期 → 解锁世业 → 有合格亲属时指定并确认交接 → 保存、继续、导出导入，核对身份与资产。按项目规则不运行 UI 自动化。

## 2026-09：婚姻、友敌、效忠与傀儡

在原有交往上增加独立 `world.relationships`。入口为左侧人物详情的“互动”及人物面板“关系与权力”，按友敌、婚姻、效忠与权力分组；显示接受度、费用、冷却、拒绝原因、关系记忆及可点击人物链。不会把效忠等同于官职直属关系。

### 婚姻与史料边界

录入萧纲—王灵宾、萧绎—徐昭佩、高欢—娄昭君三组主要配偶，关系双向可查。仅记录已覆盖的主要婚姻，不声称完整复原历史多配偶制度。萧衍为已丧主要配偶；其他未覆盖者标记“婚姻资料未录”，不默认历史未婚。本人可在游戏内明确确认建立架空婚姻起点。补充三位明确标记虚构的成年女客，提供实际可玩的结亲对象，不混入历史家谱或历史开局名录。

本轮玩法采用一位主要配偶：双方确认成年、异性、无当前配偶，排除已录近亲和同族；接受度 70、个人钱 100，双方好感 +20。婚姻不合并国库或个人资产。解除需个人钱 60、家业名望 20，双方好感 −40、压力 +15并结仇，同一对象再婚冷却 360 日。婚姻历史保留，配偶每月减压 2，并可请求亲友支援。

未实现生育、新生后代、自动死亡、完整多配偶／继承法、以结亲自动建立国家军事同盟。既有人物遗传形象接口不等于新生人口模拟。

### 友敌与资源

朋友、至交、仇敌、死敌为独立双向状态，分别影响接受度 +15／+25／−25／−40。关系页培养友谊花 25 钱、14 日，成功后成为朋友，好感 +20，并沿用家族交好威望；至交需友谊 30 日、接受度 85、钱 40。决裂消耗名望 10、压力 +10，双方好感 −30，重复决裂升级死敌，冷却 30 日；调解需钱 60、接受度 30，移除仇怨，双方好感 +15，冷却 90 日。

每月朋友减压每人 2（最多 6），仇敌增压每人 3（最多 9）。赠礼与施压对既有可玩人物复用原交往规则、特质加成和冷却；施压背叛朋友会结仇。配偶／朋友援助需接受度 40，从对方私人储备转入 50 钱，好感 −5，冷却 90 日。旧请援 70 钱、兑现人情 50 钱也扣除同一私人储备，避免重复入口制造资金。储备初始 120、每月补充 5、上限 1000，均为模拟参数。

### 效忠与实际执政

同政权可向权力更高者宣誓或招纳较低者，接受度 40／65、影响力 10／20。一人一位誓约领主，禁止循环，不将君主收入普通属员，不转移领土或官爵。忠诚初始 70，每月受亲友／仇怨和领主好感影响，归零离心。主动背誓消耗名望与影响力各 20，双方好感 −35并结仇，180 日内不得向同一领主重新宣誓；领主可释放效忠者。忠诚至少 70 的属员每月贡献影响力（最多 4）；实际执政者的忠诚属员贡献本国攻击加成（最多 9%）。

东、西魏开局保留既有名义君主与权臣格局，控制度 70。控制本国君主需军政基础、功绩 40、君主的 2 份人情、个人钱 120、影响力 60，持续 30 日。成功建立实际执政覆盖层，影响任命、改革、军务、中央官职与科层显示；失败结仇、压力 +20。控制度随月衰减，支持低于 60 时衰减更快。控制者可用影响力 20 强化控制 15，同时合法性 −3；名义君主花个人钱 50、影响力 30争取亲政，控制 −25。控制归零或主动还政即恢复君主实际权限。

原历史 `government.executives` 作为沿革依据保留，所有权限通过 `governingExecutives` 读取有效执政者。权力交替取消旧改革、在途任命并重核中央席位；政权沿革使旧控制失效。交接家业保留各人物既有婚姻、友敌、效忠，不继承前任私人关系；未完成计谋取消。

### 持久化与验收

所有关系保存在实际存档中，校验独占婚姻、历史配对、亲属禁婚、效忠环、有效执政依据、冷却和计谋随机状态。Worker 对关系及交往命令使用克隆后写入，写盘失败保留原世界。旧历史存档迁移补入已录史料关系，虚构教学局不强加历史关系。

规则测试覆盖婚姻生命周期、友敌转换、双入口资源／冷却一致、效忠与离心、夺权与亲政、实际权限变化、沿革清理、读档一致、旧档迁移、非法存档拒绝及存储失败回滚。界面待人工验收：历史沙盒 → 人物 → 关系与权力；验证赠礼、交友进度、关系链跳转、婚姻确认、效忠、控制度与读档恢复。
