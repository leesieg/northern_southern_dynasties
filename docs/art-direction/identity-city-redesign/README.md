## 设计决定

1. **政权用旌旗，家族用姓氏印记。** 共用织物、墨色、旧铜、纸签的材质语言，保持身份含义不同；家族详情、人物关联、家谱节点和列表不再各画一套盾徽。
2. **家族标识改为方形印面。** 姓氏为主体，郡望／族源／设定籍贯为第二识别层。复姓不截字；同姓不同支系保留完整名称。同族人物分属不同政权时，个人归属独立展示，不让家徽继承国色。
3. **城市保留九个同级页签。** 营建／民政／公务／军务／公库／迁运／人物／出行／沿革。统一图标尺寸、字重和纸刷选中态；州郡使用辖区／军务／公库／统筹／授官／人物／出行／沿革，不把上下级行政功能混成一页。
4. **入口、草稿、执行分开。** 查看和选择使用纸色／墨色次按钮，最终执行才使用旧金；撤回与破坏性处置用克制朱色。正文局部滚动，最后一组取消与确认常驻。
5. **保留现有城景及规则。** 图中城景插画描述色调与层次，不授权用一张图片替换已有 Three.js 城景，也不新增木石资源、建筑门槛或兵种。营建沿用市肆、城仓、驿舍；城防归军务，若在营建中出现，只作为跳转，不生成第二套建设逻辑。

## 历史取意与边界

- **忍冬、莲瓣纹**用于织物边饰和小面积印面角饰，依据故宫博物院[忍冬纹词条](https://www.dpm.org.cn/lemmas/241975.html)与[北朝扇形忍冬纹研究](https://www.dpm.org.cn/journal/249837.html)。这是时代装饰语汇，不表示某家族或某政权以莲花为法定徽号。
- **姓名、身份与印面**的表达参考印章器物。陕西历史博物馆[独孤信多面体煤精组印介绍](https://www.sxhm.com/education/detail/18464.html)可支持印章材质和身份表达的取意，但不能证明存在图中这种通行家族徽章。
- **武备插画**可参考中国国家博物馆[骑马武士陶俑](https://www.chnmuseum.cn/zp/zpml/kgfjp/202111/t20211111_252103.shtml)中的甲骑具装形象。图中人物、建筑和服饰仍是概念演绎，正式素材另做时代细节核对。
- 不将“国旗”当作已证实的现代标准国旗。具体旗形、国号排布、颜色、家族印记均为游戏原创识别系统；不宣称历史复原。东、西魏在游戏内保留完整区分，齐／周是后续国号示例，并非 546 年同时存在的五国。
- 家族来源沿用既有 `originKind`：郡望、族源、设定不能混写。武川宇文、云中独孤等不统一改称汉族士族郡望；架空家系显式标记，不挂接真实名门。

## 图像误差与不采纳项

效果图由内置 imagegen 生成并定向修订，仍可能含少量异体字、细字错误、过重按钮或微小尺寸偏差。**原始文字、原生控件尺寸样板、既有规则优先**，不能把生成误差转为玩法需求。重点不采纳：

- 图 01 的印文与完整家族名须以代码中文字绘制，不能 OCR 或截取错字作正式文字。
- 图 02 的人数、威望、家业以及族人贡献是示例；只继承已录亲缘，不把图中省略理解为无其他子女。已故／在世依实际日期显示。
- 图 03 的旗帜与关闭最终应贴在城市窗口抬头，不悬在地图独立位置；“查看营建”是次按钮。城防只跳军务；营建仍为既有三种建筑。
- 图 04 的方案名、时日、示例奏事不新增为规则；实际差事方案、预算、承办与质量来自现有服务系统。
- 图 05 的兵种、数量、征募条件来自实际军制，不采用图稿虚构兵种或门槛；公粮单位以游戏既有口径显示。请款审批者由科层确定，不能提供任意挑选审批人的下拉框；未批准不能当成已经到账。
- 图 06 的选人是授官展示，不是运粮的新增流程；撤回仍按原损耗与退款规则。人物不会因为出现在示例名单就迁入长安。
- 图 07 的沿革仅用实际存档与已录史料，不保存示意事件；只用现有统一行粮，不增加粟米／干粮／草料三套库存。
- 图 08 不增加木石、城域等级等建设前置；没有权限时确认必须禁用；家族印记与政权旗在各处必须来自同一资产配置。
