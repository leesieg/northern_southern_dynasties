# 主菜单与字体选型

类型：美术目标与字体规范提案。范围：标题主菜单、全游戏文字层级。
状态：2026-10-14 已生成三种方向与真实字体样张，待用户选型；未修改正式游戏、存档或玩法。
核对依据：`src/ui/GameEntry.tsx`、`src/ui/gameEntry.css`、`src/ui/entryRefinement.css`、`src/ui/style.css` 与 `src/ui/*.css` 的显式字号声明。

## 当前问题

- 字体依赖系统安装：正文优先 PingFang SC／Microsoft YaHei，标题优先 Songti SC／STSong／Noto Serif CJK SC。同一页面在不同平台可能改变字面、宽度、换行与气质；公共资源中没有统一分发的字体文件。
- `src/ui/*.css` 中 `font-size: Npx` 有 **37 档**显式字号，其中 10／11／12px 共 745 处声明。这是源码统计，不是最终生效文字统计；未包含 `font` 简写、`clamp()`、相对单位，也包含可能用于图标的声明，不能机械全部替换。
- 正文、页签、资源与标题缺少统一语义层级。主菜单另有大标题、19px 按钮和11px存档摘要；与新详情页的纸面、墨刷及铜饰控件语言不同。
- 需消除的不是“大字号”本身，而是相同角色大小不一致、关键说明过小、标题和内容争夺空间。字体选择必须同时验证纸面、墨底、稀有人名、数值和放大后的布局。

## 开源字体候选

| 方案 | 标题 | 正文与操作 | 推荐用途与局限 |
| --- | --- | --- | --- |
| F1 稳重史书 | 思源宋体 SC SemiBold | 思源宋体 SC Regular | **推荐基准**，统一且清晰，雕版印刷气质。小字不采用极细字重，纸面与墨底均需保持对比度 |
| F2 书札人物 | 思源宋体 SC SemiBold | 霞鹜文楷屏幕版 Regular | 更有手写温度；人物、家事、事件长文尤为合适。Screen 版改善屏幕阅读，不用假粗体模拟不存在的字重 |
| F3 古籍文书 | 思源宋体 SC SemiBold | 朱雀仿宋 Regular | 古籍气质强，适合16px起的纸面长文；技术预览字库，不推荐小字HUD全面替换，需明确备用字体 |
| 题字候选 | 马善政楷书 Regular | 不用于正文 | 仅游戏题字／大章标题，原则上40px以上；不能将艺术字推广到数字、按钮与小字 |

这些都是现代字体对书写／印刷传统的表达；宋体和仿宋并非南北朝实际存在的印刷字体。历史感来自字形、排版和材质共同作用，不用朝代名称作真实性背书。

官方来源与许可：

- [Adobe 思源宋体](https://github.com/adobe-fonts/source-han-serif)，下载文件内版本 2.003；[本地许可](fonts/source-serif-OFL.txt)。作者 `release` 分支的 SC Regular / SemiBold 原件哈希保存在 manifest。
- [霞鹜文楷屏幕版](https://github.com/lxgw/LxgwWenKai-Screen)，版本 1.522；[本地许可](fonts/wenkai-OFL.txt)。
- [朱雀仿宋](https://github.com/TrionesType/zhuque)，版本 0.212 技术预览；[本地许可](fonts/zhuque-OFL.txt)。作者说明其取意于近代仿宋活字，不是南北朝字体复原。
- [马善政楷书](https://github.com/google/fonts/tree/main/ofl/mashanzheng)，文件内版本 2.003；[本地许可](fonts/mashanzheng-OFL.txt)。

以上文件均附 SIL OFL 1.1，允许按许可随软件嵌入分发，须保留作者与许可证。不能单独销售字体；修改需遵守保留名称条款。本页子集重命名为 MenuSample 系列，保留版权许可，仅用于本提案；正式接入时另行确定完整字库和分片策略，不直接拿样张子集覆盖全游戏。

实际字体来源原件在 `.cache/menu-font-originals/`，通过隔离的 fontTools 生成本地 WOFF2 子集；不修改游戏依赖。原件与子集 SHA-256、文件版本、大小、样本缺字结果保存在 [manifest](fonts/manifest.json)。

已检查固定人名／地名样本：`萧衍 宇文泰 高欢 侯莫陈 独孤信 尔朱荣 崔季舒 郗徽 玉璧 邺城 建康 荥阳 鄱阳 鄢陵 蠡县 爨瓒 赕 颍川 契苾`。前三种正文字体全部覆盖该样本；马善政缺“苾”，再次说明它不适合作全局正文。本检查不等同于覆盖所有汉字／用户输入／未来剧本。

## 字号与排版规范（待确认）

| 语义 | 像素字号 | 行高 | 字重／用途 |
| --- | --- | --- | --- |
| display | 64–88，窄屏最低40 | 1.15 | 题字专用；艺术字400或宋体600 |
| page-title | 32 | 1.35 | 600；新建、读取等全页标题 |
| detail-title | 24 | 1.4 | 600；人物、城市、战争窗口名称 |
| value / menu-action | 20 | 1.4 | 400／600按真实字重；关键值／主菜单操作 |
| section / reading | 16 | 1.5／1.8 | 分区标题600、书札长文400 |
| body / action / tab | 14 | 1.5 | 常规紧凑正文／页签／按钮 |
| caption | 12 | 1.6 | 次级状态与单位，不承载唯一成本、阻止条件 |

建议 CSS 统一 `--font-title`、`--font-body`、`--font-reading` 和上述字号 token。限制在一套宋体加一种选定的书写字体；题字可独立作为美术资产。普通字距为0，仅短标题0.04–0.08em；避免长文逐字拉开。数字先验证实际字库的等宽数字能力，再使用 `tabular-nums`，不能只写属性就宣称对齐；必要时用独立数值列固定对齐，符号与单位不得丢失。

纸面深墨、墨底暖白、选中与执行使用旧金，朱砂仅作危险与印记；普通正文对比度目标至少4.5:1，不靠描边或重阴影补救。Map 城名为专用距离层级，保留常驻入口、按距离分档，不跟随远景无限变小。缩放需优先处理标签避让和信息密度。

常规按钮保持至少40px点击高度；图标可小但点击区不缩。建议后续提供100%／115%／130%字体设置，重排内容、局部滚动、固定确认区域可见；不对根界面使用 `transform:scale()`。115%与130%需要按窄屏、长姓名、价格、禁用原因检查，不只扩大标题。

落地顺序：确认菜单构图与字体搭配 → 定稿菜单无文字底图与独立控件 → 引入有许可的字库、统一 token → 逐组校正顶部HUD／城市／人物／国家家族／弹窗／地图 → 按真实状态与字体缩放检查。缺字、加载失败和旧系统需要显式字体回退；不在本次提案中修改运行代码。
