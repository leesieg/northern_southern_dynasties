统一细节

纸上用深墨，墨底用暖白；金色只强调选中与关键操作。保留真实字重，不合成粗体。高频数字保持横排，数值与单位分层。字距只用于题字与短标题，正文保持正常字距。地图城名作为专用层级，按距离分档但不无限缩小。

建议提供 100%／115%／130% 字体档位：让布局重排、名单局部滚动，固定确认区仍可见。缺字按显式备用字库处理，不能依赖操作系统随机回退。本页只是提案，不会写入游戏设置。
