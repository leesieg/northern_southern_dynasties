# 内战与战时军府

类型：机制说明与后续设计提案。范围：政治内战、诉求型民变、侯景事件复用的起兵、军政权限、全国站队与战后处置。
状态：2026-10-18 军府底座与 2026-10-19 A＋B（全国站队、战中博弈）已本地实施并作局部验证；界面待用户人工验收。C（完整战后赏罚）与 D（地方另立旗号）仍为提案。原方案保留，实际行为与边界见末节实施更正。
核对依据：`civilWars.ts`、`civilPolities.ts`、`politySeparation.ts`、权威权限／财政／军队规则及相应局部测试；后续提案另对照 `court.ts`、`powerPolitics.ts`、`regimentAllegiance.ts` 与所引对话。不是 CK3 规则的逐项复制，也不保证历史人物必定起兵。

## 起兵与身份

起兵沿用原有条件与代价：政治起兵需要真实支持地区、可响应军队及钱粮、私财和影响力；诉求型民变沿用当地人口、兵装费用和原组织者条件。不为保证历史事件发生赠兵、造钱或转移整州郡。

起兵后创建唯一的 `rebel-<战争 ID>` 战时政权，名称为「领袖姓名＋军府」。领袖、追随者、军队和实控地区转入此实体，原朝廷不能继续调用。军府拥有自己的中央职权、公库、任命、征募、扩编、军令和外交入口。新任官员与新征军队也按当前实际效忠办理，不限于最初响应名单。

军府领袖按将领身份与甲胄展示；军府任期只记实际执政，不因起兵生成帝王任期、冠服或庙号资格。原政治目标中的拥立对象可以仍属原朝廷；起兵领袖与拟拥立君主不是同一个概念。名义君主也可以举兵争夺实际执政权，原朝廷保持真实执政者及地方抵抗。

地图上的政权标签、城市旗帜、行旅旗帜和军旗只展示当前军府领袖姓名（如「侯景」），国家档案仍保留「侯景军府」全称。临时军府统一采用区别于梁、东魏、西魏的赭红配色；底层历史来源不变。议定割据成为正式政权后，地图恢复显示实际国号，旗帜与领土缓存随当前身份更新。

军府不占用原有六个割据编号。正式政权记录仍遵循现有上限；退役军府保留历史身份，供军饷、债务、战史和存档引用。

## 法理与实际管理

城市 `owner` 保留法理归属，`controller` 表示真正控制者。军府在原朝廷法理辖地中的实际控制形成其临时行政范围；征募、任命、差事、拨款、税收与城防使用这一范围及既有实际权限。原朝廷对这些地区的行政与军务权暂停。

新起兵即时接管真实起兵城市，县域主官撤换为起兵领袖，通过既有地方任职入口登记任期、归属及治理者；原县级任职状态撤除，避免后续结算清空新主官。仍保留原法理 `owner`，不扩大到整个州郡，也不赠兵、钱粮或人口。其他响应城市保留真实有效任职。

攻城、议降、强攻和第三国夺城均更新实际控制。战况、军府控城名单及自动收场按当前权威城市状态计算，不让历史响应名单代替现实控制。第三国夺取襄阳后仍显示第三国，不因内战收场退回梁或继续算侯景控城。

起兵只承接与响应地区、相邻敌境或在场／来袭部队真正接触的原有外战，不继承原朝廷的整套同盟、通行、停战或国际地位。后续外交用军府自己的公库、使者和真实路线。新外交条约仍限制行动。

军府可以对正式政权宣战。第三国对法理尚未议定的军府可发动赔款战争；不能借此替未参战的法理朝廷割地、吞并或扶立君主。正式领土处分仍须对应法理国家参加的和约或内战割据协议。

## 钱粮、兵员与职责

- 根据地原有地方公款及起兵捐输进入军府统筹；共享上级地方公库按实际响应人口比例分割，原账户保留余数。原中央公库不复制，不提供额外保护预算。公粮与人口仍在真实城市中。
- 随军兵员、兵籍、忠诚和欠饷保留；征募、扩编与 NPC 补兵使用实际公库、人口、粮仓和训练时间。原军饷债务及私人负担不因换旗消失。
- 军府不复制原朝廷畜群；后续真实购置的畜群在撤并时按继受者容量转入，余数保留。内战收场不改动旁观者所属国家的军务授权。
- 跨阵营的旧公职、委任与差事复核并结案，未用专款沿原资金来源退回；不继续花费敌对朝廷的拨款。幕府与誓约只带走真实响应者，不自动裹挟全部亲属或依附者。
- 控制地区恢复向军府自身输税、申请拨款和供粮；不会继续向原中央输税，也不会把军府的中央粮永久排除在补给之外。

新增数值定义：`RealmIdentity.civilWar` 是身份持有的元数据，单位为战争 ID，取正整数并对应有效内战；退役身份保留该来源。它不产生收入、兵员或战分。军府初始支持 50、合法性 40 为政权状态基线，沿用既有政治与治理消费者；不是资源奖励。`occupiedFrom` 是占领来源的政权 ID，用于外战归还实际控制，不是法理所有权或可重复计入的领土。

撤并后，请款等已结案记录按当时的真实人物与政权保留，不要求历史经办人继续效忠旧军府。外战 `inheritedFrom` 保存原军府 ID，只有真实退役身份的继受者可以承接；原朝廷与军府分别对同一敌人的既有战争仍各用原 ID、目标和占领来源，不无偿抹掉一场战争，也不允许普通重复宣战借此绕过校验。

## 收场

1. **夺权成功**：按原政治目标安排原朝廷的君位、执政或国统；军府的人、军队和实际资产并回朝廷，不另留一个重复政权。
2. **赦免／失败**：撤并军府，保留实际伤亡、私产、欠饷与债务；按胜负处理公职。溢出公库保留在退役账户，待继受账户有容量后继续转入，不截断余额。
3. **议定割据**：复用持续时间、军力、根据地和双方接受条件；同一军府成为正式政权，只划转原朝廷仍被它实际控制的县域。新增正式国统版本，保留此前军府名称与执政记录，不重建军队、公库或免费城防。
4. **无兵无地**：起兵方没有有效部队，且已无实控据点时结束；最后据点被第三国占领也满足此条件。仍有真实征募基地时，可以按资源与训练规则恢复军力。

外战记录军府辖地被夺前的实际控制者。外战议和归还时，仍存军府恢复控制；军府已经撤并则由真实继受者承接。第三国自己的有效占领与其他战事不被另一场内战静默清除。

## 旧档与验证边界

旧档校验通过后，进行中的同国双方内战一次性转换为军府实体：原战争 ID、已交战时长、伤亡、兵员及历史目标保留，转换当天不推进日期，不追扣人口、捐输或军粮，不补造已丢失的根据地。后续读入不重复转换。当前本地修改前的官方内容锁已作精确兼容登记；未知内容锁和损坏校验仍拒绝。

已是独立军府的旧档，仅为仍然实控、主官空缺且尚未建立过军府任职记录的根据地补上领袖。已有主官、主动撤免形成的空席以及被朝廷或第三国夺走的城市保持权威状态；不重新接管、不改钱粮和日期，重复载入不重复交接。

朝廷「国策／治理准则」以独立的说明容器与可选操作容器排版，查看他国没有调整按钮时，说明仍留在正常文档流；准则栏可局部滚动。内容继续读取当前军府的真实规则，不因浏览更改政策。

验证以相关规则用例、资源守恒、边界／幂等、旧档转换及正式 ES Worker 短程存读档为准。未执行长局或完整游戏回归。前端由用户人工验收，本轮没有使用浏览器自动化或截图比对。

## 2026-10-19 全国站队与战后处置方案（分期实施）

下文保留原设计；本次获准实施 A＋B，C／D 及其新增善后结构尚未实施，以末节实际记录为准。

### 1. 目标与取舍

参考对话：[介绍内战机制](chatgpt-conversation://6ad56290-6df0-83ec-b1d1-c99470f9f678)。采用其中「地方政治人物根据关系、利益与战局选择阵营，战争结束后重新分配权力」的结论；不将对话中关于 AGOT 版本、AI 或具体功能的描述作为已核验的外部事实。本方案是本作的机制设计。

在现有战时军府上增加一层全国政治动员：**地方官、将领和豪族可以勤王、响应或观望；真实响应才能改变军队和城市控制；胜败后按实际行为任免、赏赐或追责。** 保留已经实施的军府实体、独立兵政与法理／实控分离，不重做一套封臣主权体系。

首个可交付版本覆盖一场内战中的朝廷、起兵方和观望人物。地方另立旗号形成第三方，放在明确的后续阶段；其前置是解除现有「一国一场内战／单一内战查询」限制。观望不会生成独立政权。

当前 `civilWar(w, realm)` 只取第一场相关内战，起兵条件也拒绝本国已有内战。不能直接接入多个地方军府而仍沿用这个查询，否则军令、议和与自动收场会串用战争。

### 3. 何时启动全国站队

政治危机与战争动员分为两层：朝廷进入现有「危局」（`chaos`）时，在局势页预警离心原因与潜在支持者；只有真实内战存在，才发出战时表态。危局本身不自动造战争，也不让官员和平时期无故失职。

以下是首版拟定的升级条件，均为游戏参数建议：

1. 争夺执政、君位或国统的政治内战，成立后启动全国站队；侯景实际举兵复用此入口。
2. 诉求型民变先维持地方事件；叛军实际控制原战争目标都城，或者朝廷处于危局且叛军控制至少两个不同郡的已建模县域，才升级全国站队。仍保留原民变诉求，不自动改成拥立或改朝换代。
3. 每场战争只开一次动员，升级后不因暂时收复一城反复开关。战争结束即关闭；新战争使用新 ID。

「两个郡」依据真实区划父子 ID 统计，只反映本局已建模县域。外战、宫廷正常继承、执政和平交接和普通失序不会借用内战全国动员。

### 4. 谁能表态，以及三种立场的实际后果

候选集合复用 `powerStakeholders` 的在世人物、当前官职与统帅，再补充本国真实有私兵或政治影响的家族成员；以人物 ID 去重。独立决定须满足现有成年、自由与可行动规则。重病、被俘、失职者显示具体限制；未成年家族成员不被当成独立军事领袖。无权调兵的士人仍可表达政治支持、使用自己的私财，但不能凭集团身份处分公粮。

原君主、当前实际执政者和起兵领袖固定为相应阵营的代表，不进入普通反复站队名单。动员开启时，已经随起兵转入军府的人按真实身份登记为响应者，已明确勤王的人登记为勤王者并记录日期；未决窗口只面向其余合资格人物。不让已经起兵者通过首次「观望」抹去已发生的叛离。

| 选择 | 效忠与领土 | 可执行行动 | 主要代价 |
| --- | --- | --- | --- |
| 勤王 | 保持朝廷效忠；己方实控维持现状 | 在权限内响应救援、供粮与接受战役委任 | 实际军饷、路程、补给与辖地防务压力 |
| 响应起兵方 | 转入既有起兵军府；逐项办理真实军队及据点交接 | 获得军府侧的任职、军令与外交资格 | 原朝廷官职／差事结案，旧誓约及承诺后果，失败后的追责风险 |
| 观望守土 | 保持当前效忠、法理及实控；不成立第三国 | 保留地方治理、防卫和私人生活，暂不参加本场远征 | 无出征功劳，拒绝有效征召会影响关系与后续任用；遭到进攻仍须防守 |

观望保留普通税收、俸给、军饷、地方事务与已有债务。额外战时捐输和远征另行决定，不将观望做成免税、免战或免粮耗状态。叛军依现有敌对关系可以攻击观望者的朝廷辖地；不会在地图上制造不可侵犯的中立县。真正中立政权的外交地位不在首版范围内。

观望须由战役 AI 和新委任入口实际消费：相关人物能够合法控制的部队不被自动派去本场远征，但既有战役不会无声取消；主动退出须办理撤军、结案及退款。首版不新增「拒绝君主一切直接军令」权限。君主仍可依法改任统帅；原统帅若因此选择叛离，必须通过真实兵员响应流程，不能把整支官军视为私人财产。

### 5. 刺史、太守、将领怎样带来真实响应

**行政上级的表态是一项压力来源，不能直接覆盖下属选择。** 刺史勤王、太守响应叛军、县令继续守朝廷都可以共存。中央任命、地方治理、驻军指挥和士兵忠诚分别检查。

响应前生成唯一的交接预览，起兵与战中倒戈使用相同规则：

- **人物**：只转移确认响应者。亲属、集团成员、幕僚不自动换阵营；私产仍属于本人。兼任公职按真实任命与新效忠逐项复核。
- **军队**：以 `regimentFollows` 的真实私兵、追随对象、将领忠诚及制度忠诚为基础；将领换旗不保证全部士兵跟随。部分响应复用兵员拆分，按比例分割现有军粮、欠饷和余数，保持来源。不能拆分、处于交战结算或存在有效军令冲突时，在预览中排除并给出原因。
- **城市**：县域主官响应，或其本人合法控制的响应驻军取得当地实际优势，才进入可交接集合；必须是本方仍实控、属于本场冲突范围的县域。下属明确拒绝、存在有效抵抗驻军、敌军正在夺城或第三国实控时不和平换旗。无有效抵抗驻军时，实际履职的县域主官可以办理交接；州郡主官不能只凭上级头衔转走整个辖区。
- **财政**：仅交接响应县域对应的真实账户份额。共享州郡账户按当次尚存余额与剩余响应人口计算，原侧保留余数；已承诺专款、欠款、在途物资先按来源处理。不能在每次新增响应时反复按开战总额分割。
- **城防与资源**：既有建筑、公粮和人口留在真实城市；和平响应不按攻城再次扣人口，也不刷新驻军、仓容或城防。法理 `owner` 保留，`controller` 变为实际接收军府。

县域受阻时允许预览「本人携已响应兵员归附，城市仍属朝廷」，并明确失去的官职及实际道路；没有能带走的兵员也可以个人归附。是否离开驻地沿现有行旅与边境规则办理，不瞬移到领袖身边。

所有交接先复核整份预览再提交。状态变化使预览失效时返回新结果，不允许先扣款、改效忠，再因军队或公职检查失败留下半次操作。NPC 同样调用此入口。

### 6. NPC 怎样决定，怎样避免反复横跳

增加纯规则函数 `civilStanceEvaluation(world, warId, personId)`，返回资格、可行选项、因子、倾向和可携资源。它不直接写世界。`powerSupport` 的关系、亲缘、誓约和承诺计算可提取共用部分，但战时评分独立，避免和平拥立的支持度被误当成倒戈概率。

采用一个解释性倾向值：`D = clamp(各项之和, -100, 100)`，正值倾向起兵方，负值倾向朝廷。它是当次人物决策的派生值，不持久积累、不消耗、不产钱或兵，也不是成功率。首轮参数如下，均待局部规则用例校准：

| 因子 | 对 D 的拟定范围 | 权威来源与约束 |
| --- | --- | --- |
| 对双方实际领袖的关系差 | −30～30 | `relationOpinion`，人物对领袖的同向比较，避免反向读取 |
| 亲缘、婚姻与政治受益对象 | −25～25 | 当前在世亲缘、有效婚姻与 `PowerArrangement`，不按姓氏硬编码 |
| 誓约与保留待遇 | −30～30 | 当前誓约、有效且有权限兑现的承诺；同一承诺不重复计分 |
| 现有合法性与任职利益 | −20～10 | 原朝廷合法性、真实职位及目标是否威胁本人的职位／君统 |
| 政治目标与集团诉求 | −15～15 | 集团满意度和目标相容性；领袖响应只增加倾向，不强制成员响应 |
| 性格 | −10～10 | 现有特质，限定调节冒险、守约和保守倾向，不新增无消费者特质 |
| 当地军力、通路与生存风险 | −15～15 | 本人据点附近可到达的实际军力、缺粮及撤退条件，不用全国总兵力代替当地危险 |
| 已公开的战局变化 | −20～20 | 本场有效战分、都城控制、领袖被俘等；单项冲击封顶，不以一战强迫全国倒戈 |

默认 `D ≥ 25` 倾向响应，`D ≤ −25` 倾向勤王，中间为观望；最终还须通过资格与交接检查。双方各有强亲缘／有效誓约且分差不够时优先观望，展示「两方皆有牵系」。被迫违背明确誓约的代价进入确认与后续关系结算。

初次表态窗口拟定 15 日；NPC 在窗口内按当前可见局势作决定，玩家使用待办直接进入选择。玩家超时默认维持原效忠、守土观望，关闭本次待办；不替玩家响应叛军、花费私财或派军。可以暂停阅览和暂缓，不因全国其他人的表态无限锁住游戏时间。

战争期间拟每 30 日重评观望者，重大事件则标记相关人待重评，在下一次世界结算处理。已经参战者改投另一侧需距上次主动站队至少 60 日，且新侧倾向达到 45 点；观望加入一侧使用 25 点门槛。死亡、被俘、官职撤销先走失效与交接规则，不用冷却强留一个无效人物。评分相同采用保持现状与稳定人物 ID 排序，不每日随机投骰。

因子、阈值和到期日须与 NPC 执行共用计算。玩家界面显示真实理由、代价和当前预览，不显示「65% 倒戈」之类未经定义的概率。尚未公开的私人计谋、承诺不向旁观者泄露。

### 7. 玩家怎样干预，界面放在哪里

主入口沿用战争旗帜 → 战争详情，增加「地方响应」分区：按勤王、响应、观望列人物，常显实际职位、驻地、可动员兵员及已执行贡献。州郡汇总由县域派生，可以显示同州分裂，不另建一套可手改的州郡阵营。

人物详情「互动」放针对该人物的招抚／劝勤王入口，直达同一战争的谈判弹窗；局势页显示总体离心原因并直达战争。朝廷不再复制整套名单。玩家本人需要表态时，顶部只生成一面关联原战争的待办旗帜，采用现有旗面规则，不额外叠通用特质图标。

选择立场、挑选调动军队／捐输来源与最终执行分开。弹窗常显原阵营、新阵营、会转移及不会转移的县域和军队、真实钱粮去向、撤职／退款及誓约后果；确认区常驻。选项失效、目标死亡、战争结束或切换对象时清理草稿，执行按最新世界复核。

第二阶段再加入定向游说与待遇承诺：承诺保留某职位、授予合法可任的空席或保留某支真实兵权。复用政治承诺履约检查，补上战争来源与具体对象；不能同时把同一空缺许给多人，也不能许诺第三国官职或并非自己能处分的部队。承诺只是将来义务，履约时仍走任命、赴任与支付规则，不生成官职或先发无来源赏钱。

承诺须区分「立即保留现职」与「战后办理授官」的生效条件、到期日和失败结果。后者在约定政治结果成立后进入办理期，不能因战中尚未授官立刻判违约；到期未兑现先结算违约与政治后果，再归档，不静默删除。败方无权兑现的承诺明确作废，已经付出的真实费用不凭空退还。

地图继续用真实 `controller` 决定领土色与旗帜，起兵方只显示领袖姓名。观望用详情内的状态标签表达，不更改国界、创建伪国号或叠新地图图例。最终布局与视觉由用户人工验收。

### 8. 战后按行为结算，不照开战名单清算

保留现有「夺权／赦免／失败／双方议定割据」四类政治结果。军事停战、资产撤并和政治处置分开：撤并前固定最终阵营、行为和承诺，原子创建有明确权威主体的善后记录，再结算战争及资产并移除活跃战争；操作失败整体回退。不能先把所有人并回朝廷，再从已被改写的效忠推断谁曾经叛乱。未完成封赏不妨碍正常推进日期。

记录实际响应、拒绝征召、交战、占领、供粮、违约和倒戈的来源；只有成功结算的行为计入，不用表态次数刷功。贡献按战斗作用、实际守／夺城、净供给分别展示，军队和统帅不能重复计算同一份兵力／功劳；供给以真实送达及未退回数量为准，循环调粮不累计贡献。首版使用分类事实与排序，复用既有功绩奖励，不再创造一种可花费的「内战贡献点」。

| 事项 | 首版实际操作 | 权限与闭环 |
| --- | --- | --- |
| 抚慰与留任 | 赦免、确认合法有效任职，或者经现有入口改任 | 白和平约定的赦免限制追责；不能恢复死者、敌占地或已由别人合法担任的职位 |
| 论功 | 支付赏钱、提出合法授官／保留军权方案 | 赏钱从胜方真实公库到个人私财；职位有资格、空缺／撤换及赴任检查，不能凭排名重复领赏 |
| 追责 | 撤免败方公职；对已实际拘押者沿现有审理／处置入口办理 | 在外、仍有兵权的人只能收到交涉／撤免决定，不能凭胜利直接被捕或处死 |
| 兑现承诺 | 将有效承诺接入现有履约链，显示已兑现、待办理或违约原因 | 领袖死亡、换任、席位冲突和资金不足均明确结案或继续有期限处理 |

没收整族私产、人质和流放不作为首版新增操作；必须等真实资产权属、收押／迁移与后果路径完整后再接入。严罚的政治后果先复用现有关系、合法性与集团满意度消费者，不为界面新增一条没有下游作用的「暴政值」。

取消现有按起兵支持名单一刀切处理所有失败方地方官的做法，改用最终阵营、实际行为、和约承诺与当前任职判断。既有统一撤免逻辑须在善后接入时一起替换，避免先自动撤掉又在弹窗中假装允许留任。

战争结束不能按战前快照把所有人、城和官职强行复原：第三国占领保留；实际死亡、伤亡、现任合法官员、欠饷、债务和未完外战继续有效；军府撤并的资源仍走已有容量与继受链。

### 9. 状态结构、命令和保存边界

以下为拟新增结构，不是已存在字段。优先将动员附在 `CivilWar.mobilization?`，不增加第二套国家／军队实体：

| 数据 | 类型与持有者 | 来源、范围与消费 |
| --- | --- | --- |
| 动员来源与阶段 | 本场内战的元数据／状态：版本、触发原因、原朝廷／原国统 ID、阶段 | 创建时写入，阶段为征询、持续或收场；目标仍引用战争原有政治安排，不复制另一套目标 |
| 人物立场 | 本场动员按人物 ID 的状态：未表态／勤王／响应／观望／失效 | 保存选择与失效原因；当前效忠、军队所有权、城市控制仍以原权威实体为准，禁止从此表反向覆盖现实 |
| 表态与冷却日期 | 人物动员记录的时间元数据，单位游戏日，安全非负整数 | 创建／合法选择时写入，消费于 15 日窗口、30 日重评和 60 日冷却；不是可累加进度或资源 |
| 交接回执 | 每次真实交接的事务元数据：战争／人物／修订、来源、去向、资源及凭据 | 与权威财政／兵籍操作一起产生；用于幂等与历史解释，不作为另一份可用钱粮余额 |
| 实际参与记录 | 本场动员的行为元数据及分类汇总，引用真实战斗、占领、供给与违约凭据 | 按来源事件 ID 去重，聚合实际行为并在终局交接；不与既有功绩重复发奖，不产生可消费的贡献货币 |
| 评分与可携资源 | 当次派生预览，分值 −100～100；资源使用原本的单位及容量 | 不写成每日快照，改变世界后重新计算；解释值不计入政治势力或资源总额 |
| 战后善后 | 拟在 `PowerPolitics.civilSettlements?` 保存按战争 ID 的终局摘要、逐项处置状态与引用凭据 | 活跃战争删除前原子移交；之后战争不再持续，未决封赏／追责仍有入口；不能只挂在即将删除的 `war.civil` 中 |

新增政治选择命令与原 `respond` 的军务动作分开，拟使用 `civilWar/stance`，携带战争 ID、选择及预览修订；游说、承诺与善后各用明确命令。所有请求仍由 Worker 写入入口办理，UI 只读预览；重复命令通过状态修订、资金凭据与已结案标识拒绝重复扣奖。

战中交接应新增 `joinCivilCamp`／`civilTransferPreview` 等职责明确的规则入口，提取起兵时真实转移的共用步骤；不能对每次加入再调用一次创建政权的 `establishCivilPolity`。不以新抽象替换整个财政或军队模块。

旧档兼容：已有军府的当前效忠、实控与兵籍决定初始立场；已登记救援回应保留，不将历史 `wait` 无条件解释为政治中立。进行中的合资格内战从载入后本局日期开一次新征询，不补造过去的贡献、捐输、承诺或反复分库；未开战存档保持原状态。新版本先校验旧形状、再一次迁移，反复读入幂等。新增字段须补充存档校验与精确内容锁兼容，不扩大接受未知内容锁的范围。

战争 ID、人物、政权及资源凭据必须可追溯；终局摘要保留实际结论，逐次评分不持久化，不靠无限追加每日日志解释 AI。实现字段后再按项目规则更新数值审计并生成字段清单；本次仅提案，不改现有字段清单与数值结算。

### 10. 死亡、被俘、换任与其他战争

| 边界 | 规则 |
| --- | --- |
| 原朝廷执政者死亡／换任 | 当前宪制继承先结算，再更新勤王一方的实际领袖；不让旧领袖 ID 锁死表态或谈判 |
| 起兵领袖死亡／被俘 | 首版沿用现有内战收场条件；先关闭其未决表态与承诺，再走资产撤并及善后，不顺带引入军府继承新玩法 |
| 拥立对象失效 | 复用现有政治目标重定或收场；重算目标相关倾向，不重复开全国动员 |
| 候选人失职、死亡、换国或被俘 | 关闭无效待办、撤销未执行草稿；已发生交接／损失保留；后来恢复自由按当前身份重新取得资格 |
| 最后据点失守、无兵 | 沿用当前真实无兵无地收场；仍有合法补兵基地时继续。善后不重新生成起兵城市 |
| 多战争及第三国 | 表态只作用于指定内战；不自动退出外战、继承所有条约或赠送第三国领土；交接涉及正在其他战争执行任务的部队先处理真实军令与资金 |
| 观望者遭攻击 | 直接防卫照常，战局成为重评依据；不因为观望标签拒绝发生战斗 |
| 玩家不在交战国 | 只接收已公开的战事与站队消息；无代投票、代花钱或影响本人国家军务权限 |

### 11. 分阶段实施与完成条件

| 阶段 | 实施内容及主要位置 | 完成条件 |
| --- | --- | --- |
| A：全国表态与真实交接 | `civilWars.ts`、`civilPolities.ts`、`regimentAllegiance.ts` 增加共用预览／交接；新增 `civilMobilization.ts` 处理范围、候选、评分和状态；接 Worker、存档校验与最小响应弹窗 | 同一场内战可以出现勤王、响应、观望；开战后新增响应真实转兵／转城／转账；上下级可异侧；反复读档与命令不重复转移；观望部队不会被本场 AI 自动远征 |
| B：战中政治博弈 | 加入定期重评、重大事件重评、冷却与定向游说；对接 `powerPolitics.ts` 的具体待遇承诺与履约检查；完善 `WarDetails`／`PowerPoliticsPanel` 和人物入口 | 可从观望加入一侧、满足条件后倒戈；每次有可解释原因和实际代价；承诺占用真实可处分对象，不一职多许，玩家始终自己选择 |
| C：战后秩序 | `settleCivilWar` 生成独立善后记录并替换名单式统一撤免；复用任命、公库支付及拘押处置；战争详情保留终局入口 | 战争正常结束后仍能处理封赏／追责；赦免约束生效，只有实际拘押者可被处置；赏钱守恒、功劳不重复、债务与第三国占领保留 |
| D：地方另立旗号 | 将内战关联由单次查询改为显式战争／危机范围，扩展军府身份、友敌判断、外交、AI 与多方和约 | 一个地方势力可凭实际据点、兵员、资金另立军府；与朝廷及原叛军的关系各有依据，多方收场不互相撤并、不串占领或重复封赏 |

建议首轮实施 **A＋B**，让侯景起兵后真正发生地方响应、观望与倒戈；随后完成 C 的政治闭环。D 作为后续扩展，不能用给观望者临时换一个政权 ID 来提前冒充完成。

D 阶段的「自立」是新的举兵行动：满足当前起兵资源、驻地与真实兵员资格后建立新实体，并明确自己的政治目标；不是点击一个立场就免费独立。达到议定割据条件后，该实体才转为正式政权，且只处分谈判各方有权交割的实际县域。无地无兵、超过本局身份／军队容量或缺少独立外交资格时给出真实阻止原因。具体多方和约细则在进入 D 前补齐，A～C 不依赖该扩展才能完成。

### 12. 局部验收与侯景用例

以下是实施时需要通过的局部规则与集成用例，不代表本轮已经测试：

1. **上下级分裂**：州刺史勤王、某太守响应，只有该太守真实可交接的县域换旗；不扩大到全州，忠于朝廷的县令及有效抵抗驻军能阻止和平交接。
2. **部队部分响应**：统帅支持侯景，制度忠诚较高的兵员留朝廷；两侧兵数、军粮、欠饷与拆分余数守恒；容量不足时预览和执行一致，不留下半次扣款。
3. **真实观望**：NPC／玩家观望后照常治理、输税、领薪及防卫，本场 AI 不自动派出其可控制部队；玩家超时不换效忠、不支出、不锁时钟。
4. **持续博弈**：侯景取得真实胜利或建康失守只触发一次相关重评；存在强誓约者仍可能勤王，观望者可归附；60 日冷却和更高倒戈门槛抑制往返刷收益。
5. **事件共用**：侯景历史事件成功起兵后只创建一次全国动员；来自普通政治起兵及民变升级的同类情况走相同函数。高欢死亡、河南来书、无兵个人安置等起兵前环节不被全国站队反向强制推进。
6. **重复与旧档**：同日结算、重复命令、读档迁移不重复分库、造兵、计功或生成待办；旧军府实际已丢失的城市不恢复，旧 `responses` 不变义。
7. **收场**：首领失效、最后城市被第三国夺走、割据／赦免／失败各走正常出口；善后记录在战争移除后可访问，第三国占领、其他战争、债务及未完资源运输保留。
