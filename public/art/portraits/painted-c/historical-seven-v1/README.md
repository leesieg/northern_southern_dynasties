# 魏收等七人历史画像生产素材

2026-10-21。用户授权八张效果图完成后直接接入，不再等待确认；实际界面仍待人工验收。[原图、来图、年龄与史料边界](../../../../../docs/art-direction/portrait-studies/historical-seven-546-v1/README.md)保留在项目内。

本目录包含 30 张 1024×1536 PNG：七张人物原件、七张四格换装、十四张对应去五官底稿，以及陈蒨皇帝原件和独立去五官底稿。四格顺序为左上常服、右上治事、左下军旅、右下君主，每格 512×768。[完整实际生成提示词](prompts.json)登记 22 次成功的配套生成与初次批次参数失败的原因；主原件的八次提示词见预期图记录。

- `*-canonical-faces.png` / `*-canonical-base.png`：主原件与对应底稿。
- `*-faces.png` / `*-base.png`：四格换装与对应底稿。
- `chen-qian-sovereign-faces.png` / `chen-qian-sovereign-base.png`：用户第二张陈蒨参考形成的皇帝版本，与官员版共享身份和基因。

魏收、元廓、萧渊明和萧懿以原件为常服；元钦、陈蒨以原件为治事服；李虎以原件为军旅。实际选衣依世界中的任职和领军身份，原图不授予官职、军队或君位。陈蒨实际成为君主才用独立皇帝原件；通天冠无冕旒。七人均使用成年登记，其他剧本低于 16 岁时沿用现有幼年系统。

`historicalPortrait.ts` 对八张原件和二十八个身份格分别登记眉、眼、鼻、口及方形头像，未沿用旧底图坐标。继续采用八层组合、稳定初始基因基线、有界遗传变形、健康／年龄／已故叠层、消息透明边缘和有限缓存；原三十二人登记保留。萧懿是 500 年已故先人，享年 50，显示去世状态；可选换装仅供既有美术样板比较，不使其复活、授官或成为候选君主。

新人物沿用权威名录和家谱：`xiao-yi-elder` 为萧懿，不与 `xiao-yi`（萧绎）混用；`xiao-yuanming` 为萧渊明。现有存档升级只补两位新人物所需记录，已故者不获得活动账户，在世新增人物私人储备、威望及影响力从零补录；旧人物资源、健康、基因、行程和政权保持。年龄展示统一按整数显示，推定来源继续保留在数据与资料中。

人工入口：[人物画卷样板](../../../../../docs/art-direction/portrait-studies/style-c/roster.html)，可选人物、身份和年龄；实际游戏按世界状态显示。需人工确认五官组合、头像裁切、完整立绘、消息边缘和已故叠层。文件与代码检查不代表视觉已验收。
