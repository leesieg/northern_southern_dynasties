# 身份朝服 · 2026-10-09

本目录是完整人物底图，不是无头衣身。每张 `*-court-v2.png` 为双联图：左为君主，右为官员。多数为 1448×1086，四张为 1447×1087；真实尺寸登记在 `src/data/courtAssetSizes.json`，等宽取左右格后映射回原画坐标，不裁掉边缘。儿童右格不用于任官；幼主使用左格，其他儿童继续原有儿童配方。常服、贵族和军旅入口保留原有文化肖像／甲胄。

## 服饰依据与边界

- 君主参考传阎立本《历代帝王图》的冠服层次，以玄色、朱色、素色中衣、大袖和绶带区分身份。萧衍模板用通天冠式高冠；其他男性君主用冕冠。冕板沿头部前后方向延伸，旒列悬于前、后短边，前在额前、后在脑后；长边不挂左右珠帘。
- 官员参考《北齐校书图》等画作的袍服与冠帽轮廓，采用较收敛的黑冠、深绿／赭朱袍、素色内领和腰带。颜色用于人物间的视觉变化，不声称按唐宋品级服色复原南北朝官制。
- 女性君主、女性任官和幼主衣装适配本局身份，是游戏美术演绎；不能据此断言具体历史人物曾任该职或穿过该服。保留女性及儿童原有身形、发型与五官模板。
- 传世画作并非每位人物的同时代写生；珠数、章纹与比例经过游戏缩略显示简化，不作为逐朝礼制考据。没有加入明清补子、清式冠帽或宋式长翅幞头。

参考目录：[波士顿美术馆《历代帝王图》展览介绍](https://www.mfa.org/exhibitions/chinese-master-paintings-collection)、[芝加哥大学《帝王图卷》](https://scrolls.uchicago.edu/view-scroll/61)、[波士顿美术馆《北齐校书图》数字藏品](https://artsandculture.google.com/asset/northern-qi-scholars-collating-classic-texts-unknown/zAEEgYzPdibGvw?hl=zh-cn)、[《太平御览》卷六百八十六冠服记载](https://zh.wikisource.org/zh-hans/太平御覽_(四部叢刊本)/卷之六百八十六)。画作仅作参考，未导入馆藏图像作为游戏素材。

## 接入与生成

使用内置 ImageGen 基于项目原画编辑，未使用外部 API／CLI。最终提示词与参考文件见 `prompts.json`。v1 草稿错误地把冕旒画到两侧，按用户纠正作废；v2 统一以前后结构为准。原稿留于本地生成记录，不作为正式资源。

`approvedPaintedRecipe → courtCostume` 按当前身份选完整朝服，头部和身体取同一幅画且保持原有比例；六处五官继续读取原始五官图、采样坐标和存档遗传参数。放置位置与尺度由 `src/data/courtFaceRegistration.ts` 按两格分别登记，再同步变换头像裁切，不重抽外貌，也不重新拼接颈部。素材路径及配方版本进入现有缓存键。实际官职复用 `portraitRank` 的活动官位与优先级，执政者不因拥有军队换为统帅衣装，失去有效官位后恢复原有衣装。

2026-10-09 脸部校准：原实现错误地假定新底图保持原脸坐标，导致高欢等人物贴脸偏移。本轮检查 19 套、38 格源图（儿童官员格不接入）；结合耳、颊、下颌的位置登记等比变换，避免让冕旒和新增须发干扰定位。高欢、萧衍、通用女性、北地女性、元钦、徐昭佩及元善见专用模板应用修正，其余保留经检查的恒等变换。全程未修改位图；源素材位置分析不代表实际游戏画面已获人工验收。`face-v1` 配方标记使旧错位缓存失效。

原画素材可在此目录查看；游戏中的实际五官叠合、冕旒遮挡、头像裁切、服饰效果须人工验收，代码与素材检查不代表视觉验收。预览入口为 `/output/portrait-direction/style-c/roster.html`，身份选择只改变预览，不写存档。
