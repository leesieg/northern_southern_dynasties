## 身份、遗传与共用入口

十一人加入 `historicalPaintedRecipe`，共用注册现覆盖三十二人；原二十一人的规则与素材保留。复用人物详情、名单、选人、席位、地图小头像、消息／事件透明立绘与缓存，保留身份框、年龄、病容和去世效果。

服饰由实际世界身份选择，不据参考图授予军队、官职或君位。当前开局萧纪为治事身份，其余十人为常服；有军旅经历但当前没有领军／相应职位者，沿用现有身份规则。任职、领军、卸任或继位后自然换装，四格君主服不预设即位。新人物均使用成年登记；早于 16 岁的其他剧本年龄仍由通用幼年系统处理。

每张确认原件和每个身份格分别观察登记眉、眼、鼻、口及方形头像，未复用旧底图位置。沿用八层合成和最多 ±6% 的有界五官调节，稳定原有初始基因显示确认画面，旧档中真实基因差异使用配套底稿合成，不重抽或覆盖遗传。羊鵾登记无须，其余十人保留画中须发。

萧詧保留小型骷髅形陶杯，双眼无遮，与既有萧绎眼罩登记分开；道具不表示已核实嗜好或产生玩法效果。彭乐使用健康完整的画面，不把参考战斗出血固化为当前伤势。衣冠、甲胄、五官和道具均含艺术演绎，不能据图认定精确历史容貌或装备制度。
