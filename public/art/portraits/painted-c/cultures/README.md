# 完整文化肖像（2026-10-03）

成人恢复「完整原画＋局部五官变化」，不再运行头部、衣身和冠帽的独立拼合。汉文化复用 `../roster/` 的原画；本目录新增 15 张 1024×1536 的鲜卑式完整衣装变体，对应全部非甲胄成人底图，包括男女及青年、壮年、老年模板。每张都有完整脸部、颈肩与手臂，不能作为无头衣身使用。

独孤信、陈霸先的甲胄模板及君主礼服继续使用原画，体现军事／礼仪场合；不强称每件盔甲为某个文化独占。儿童保持已接受的 `costumes/child-v2.png` 组合。敕勒、羯及未详文化保留独立文化标签和原画，未声称补齐其专属服饰。

新增图按原人物分别编辑，保留身份、发型和姿态，以窄袖、收口、束带及衣领体现鲜卑式衣装；这是游戏美术概括，不是所有人物在所有场合的历史着装断言。成年人的任职不会再自动套入三类衣身；官职仍由真实身份、边框和文字展示。

生成方式为内置 ImageGen，未使用 CLI/API。所有参考图来自项目既有已接受原画，未覆盖旧文件。每个文件的最终提示词和参考路径完整保存于 `prompts.json`。生成图存在轻微面部位置变化，`src/data/wholePortraitBounds.ts` 按实际图面重新登记六处五官；基因只改变这些局部区域，整幅底图不变形。画中外貌不根据民族调整肤色或血统。

读取链路：`approvedPaintedRecipe → wholeCulturalPortrait → renderPaintedPortrait`。同一新图提供头身和五官采样，头像裁切也取自新图的面部登记。源文件及配方变化进入现有肖像缓存键，无世界日重绘或存档迁移。

素材尺寸／覆盖、儿童保持、遗传边界、头身不变形与缓存通过局部测试；原画对照和实际游戏入口做截图检查。最终美术效果仍由用户验收。详细结果见 `docs/更新日志/084-文化身份服饰与地方诉求.md`。
