# 五位历史人物肖像运行素材

2026-10-17。用户已确认宇文泰、高欢、萧衍、侯景、陈霸先的五张预期图，并明确要求接入游戏。本目录为对应的生产素材，原始预期图与来图见 [美术目标记录](../../../../../docs/art-direction/portrait-studies/historical-five-546-v1/README.md)。换装与游戏内显示待用户人工验收；素材目视检查、代码测试不补认 UI 验收。

- 每人 `*-canonical-faces.png` 是已确认预期图的逐字节副本，1024×1536。宇文泰／高欢的执政、萧衍的君主、侯景／陈霸先的统军身份直接取此画面。
- `*-faces.png` 为内置 image_gen 从该人的预期图生成的四格换装图集：左上常服、右上治事、左下军旅、右下君主。实际生成尺寸为 1024×1536，每格 512×768；未用插值放大冒充更高源分辨率。原开局图仍保留完整 1024×1536。
- `*-canonical-base.png`、`*-base.png` 是对应的去五官底稿，分别用于原图和四格图集。生成图原件保留；未离线裁图、合成、重绘或修改原图像素，运行时 Canvas 负责取格、遮罩及组合。
- 五张完整确认图、五张完整图底稿、五张四格图集及五张图集底稿，共 20 张 PNG；完整实际提示词见 [换装提示词](prompts.json) 与 [底稿编辑提示词](blank-prompts.json)。衣冠、容貌与后续假想身份服饰是美术演绎，不是历史真实性保证。

`src/character/historicalPortrait.ts` 按人和身份格独立登记六项五官采样及头像裁切；不复用旧脸坐标，也不将新脸借给宇文护、独孤信或普通 NPC。人物仍走八层绘制、共用缓存、头像和透明立绘流程。成年男性且匹配稳定人物 ID 时采用本组，女性与未成年回到现有对应规格。

确认图对应该人的既有初始遗传参数；未变化的基因使用原图，存档中的真实参数差异才启用去五官底稿并作最多 ±6% 的有界调节。换装不重抽基因、不改世界。实际职位由 `portraitContext` 决定，君位变化才采用相应君主服饰；无统军／官职时按实际身份显示常服。年龄、疾病、去世、身份边框与消息／事件的内容和裁决规则沿用现有系统，胡须变白按新画面确有须发登记。

主游戏、人物选择、消息来书、事件人物、名单、官职席位与地图标记复用同一肖像配方。人工入口为本地游戏 `/` 和原有人物样板 `/docs/art-direction/portrait-studies/style-c/roster.html`，可切换四种服饰；样板不改存档。需确认半身构图、小头像、五官变化、白冠与甲胄、透明来书人物、身份变化和年龄／健康叠层。
