# 行旅人物模型

来源：用户提供的《风云南北朝》汉文化／鲜卑文化男女旅行 GLB。原始文件未修改；源文件名、SHA-256 与处理结果见 `sources.json`。这里记录来源，不额外推定第三方素材的授权条款。

生成：在项目根目录运行 Blender `--background --factory-startup --python scripts/map-sample/rig_travelers.py -- <原始模型目录>`。可编辑绑定与动作保存在 `art/travelers/*.blend`，离线资产检查图与日志保存在 `.cache/travelers/`。

- 每套近景约 15,000 三角面、1024 像素贴图；远景约 4,000 三角面、512 像素贴图。
- GLB：Y 轴向上，+Z 朝前，归一化身高 1.72；26 个骨骼，最多 4 个顶点权重，脚底归零。
- `Idle` 2.4 秒、`Walk` 1.2 秒，动作循环不带地图位移。汉文化女性保留交叠双手与短步幅，其余三套使用自然摆臂；衣摆独立绑定。
- 按真实人物文化与性别选型；敕勒、羯、文化未详按用户要求复用鲜卑服装，仅影响外观。已知未满 18 岁或性别未详者保留肖像入口。
- 地图按实际路线位置、朝向和地形高度显示。远景／平面视角保留肖像；抵达后回到当地人物入口。详情肖像、遗传、身份与存档不变。

状态：资产和局部代码检查通过，游戏内比例、光照、袖裙变形、遮挡及交互待用户人工验收。四套旅行装不表示已实现年龄变体、三维遗传、换装或骑乘。
